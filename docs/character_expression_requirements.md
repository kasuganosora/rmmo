## 实施要求

- 建立完整、明确的 MMD 表情名称/标签与内部表情 ID 映射；眼、眉、口及其它效果分类清楚。不能只有名称而没有实际可见效果。
- 制作前核对采用的 MMD 表情命名、源模型实际形态键及覆盖范围，形成具体清单；不得把任意一个模型的键数量宣称为统一标准。当前映射见下方；不支持项须明确报错，不能悄悄当成中性。
- 除独立基础形态外，还需可用的组合表情。检查左右眨眼、眼睛与眉毛、口型和腮红组合，不出现眼皮穿眼球、嘴唇翻面、牙齿外露异常或脸部撕裂。
- 表情形态、眼部材质/图案切换及其它辅助效果可以分别实现，但对外使用统一表情语义；不能给每个预览或 NPC 单独做一套。
- 复用统一人物系统，状态按角色实例隔离；表情混合与归零不重建人物，也不改变已经认可的身体和衣服。
- 验收包含正面、侧面、过渡和组合；同时检查原灯光场景与游戏视图，不能只凭一张静态表情图宣布完成。

## 当前实现与命名覆盖（2026-09-29）

名称核对参考作者直接公布的[MMD形态名称统计及筛选](https://gist.github.com/lilxyzw/80608d9b16bf3458c61dec6b090805c5)。这是一份实际使用调查，不是统一强制标准；其中眉毛「にこり」不能用眼嘴微笑组合冒充。

| 分类 | 内部ID | 对外标签 | 实现 |
|---|---|---|---|
| 眼 | blink / wink_left / wink_right | まばたき / ウィンク / ウィンク右 | 源左右闭眼形态 |
| 眉 | brow_up / brow_down / brow_worried / brow_angry | 上 / 下 / 困る / 怒り | 源眉形态 |
| 口 | a / i / u / e / o | あ / い / う / え / お | 源元音形态及下颌/舌骨公式 |
| 口 | mouth_smile / mouth_frown | にやり / 口角下げ | 源嘴角形态 |
| 组合扩展 | smile | 微笑（組合せ） | 眯眼+嘴角，不等同独立「笑い」或眉「にこり」 |
| 材质扩展 | heart_eyes / star_eyes / circle_eyes | ハート / 星 / 丸目 | 本项目风格图案，不宣称通用标准 |
| 其它 | blush | 照れ | 面部UV腮红，独立连续权重 |

Model.set_mmd_expressions接受上表标签和0..1权重；未知项拒绝且保留原状态。它是运行时名称映射，**不是VMD播放器或PMX导入器**。直接ID API支持连续混合，HUD按类组合和取消。截图及回归见第七十五批。

剩余清单：专门闭眼笑「笑い」、眉毛「にこり」和「真面目」等目标语义需逐一核对源形态；惊讶/挤眼要有实际效果，不能只挂标签；更多体型/动作/光照组合，以及远端同步尚未验收。此表不以别的模型165键的数量作为完成标准。

## 第七十六批补充

新增标签：eye_smile→笑い、eye_surprise→びっくり、eye_squeeze→ぎゅっ（扩展）、brow_smile→にこり、brow_serious→真面目，均有真实源形态组合。眼部标签只改变眼周，嘴角/元音可单独组合。已接mocker校验、事件、远端快照和乱序保护；不是Go/真实多客户端联网。三组height/nose_width参数仅覆盖本次实际支持的形态组合，不等同所有脸型。原灯光场景验收见第七十六批进度。
