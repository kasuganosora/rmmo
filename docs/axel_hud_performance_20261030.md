## 独立复现与修复

### UI 更新范围与生命周期

`test_hud_refresh_scope.gd` 使用真实 HUD、六个窗口及 3D 地图视图，headless 只测更新 CPU 工作。
原版背包/装备/任务/技能目录/属性/冷却更新各耗时 65.9–75.1ms，连续 20 次冷却通知 1395.886ms。
原版会重建地图、重置平移缩放、销毁设置控件；同帧重复重建还产生延迟回调引用已释放 MapHost 的错误。

修复：

- 每种快照只刷新依赖它的窗口；冷却直接更新现有技能控件。
- 金币更新直接修改背包及角色窗口的金额标签；当前 HP 变化只更新状态条，不重建展示最大数值的纸娃娃窗口。
- 相同背包/技能目录及已交付装备快照去重。装备必须对比最后一次 UI 交付，不能对比可能已被背包/快捷栏读取更新的服务端缓存。
- 装备变化仍更新纸娃娃和背包装备比较提示；等级变化仍更新技能学习条件。
- 重建背包不再覆盖已收到的钱包值，也不把权威空背包误当作“尚未收到快照”。
- 地图延迟布局回调执行时查找当前控件，完整角色重新绑定仍可显式重建全窗口。

最终专项用例 `refresh_scope_final_03`：40 项通过，0 引擎/脚本错误。
真实装备变化 51.582ms（纸娃娃 + 背包两处必要刷新），任务 3.526ms，当前 HP 0.515ms，冷却 0.256ms；20 次冷却共 0.640ms。
这些是独立 CPU 测量，不冒充整图 FPS。原版装备只在角色窗口打开时刷新；本轮补齐背包比较提示依赖，不能把两者时间直接当作同工作量比较。
另以 `refresh_scope_final_04` 补验初始装备快照已经交付、随后背包先读取新装备的真实顺序，仍为 40 项通过、0 错误；这次必要的装备双窗口刷新为 66.839ms，20 次冷却共 0.638ms。装备窗口自身构建仍有继续分摊工作的空间。

### 远景代理的无效准备

当前地图未开 HUD 也有周期长帧。官方 profiler `baseline_on_profiler.bin` / `_official.json` 显示：

- 远景代理 `tick` 208 次、包含调用链约 34.97s；其中 `_snapshot` 6062 次、包含约 28.60s。
- `material_key` 113971 次，脚本自身约 19.72s，单帧自身最高约 113ms。
- 多个近处候选先读取/整理几何及计算材质摘要，最后才按整个建筑包围盒中心拒绝远景代理。候选节点原点只做了宽松初筛，不能替代实际距离判断。

修复把完整候选包围盒判断提前。仅判断材质是否允许合批时复用轻量支持条件；真正接纳后仍计算原来的完整材质摘要、精确几何和 LOD，不放宽材质、距离、选择、碰撞或楼层隐藏语义。

## 整图交错对照

`optimized_on_01` 是第一版有效修复；后续补齐 UI 重复快照、金额标签和装备交付顺序，最终版本单独复测。
原版恢复后耗时再次上升，支持真实的代码收益；没有将首轮缓存预备时间差当作收益。
最终无错误样本相对恢复原版：完整就绪约减少 14.2%，稳定 p95 降约 69.6%，1% low 提升约 2.54 倍。
99.678s 的较快样本同样保留，但不能只挑它报告；115.842s 仍明显偏长，稳定期仍有 83 帧 >50ms。
入口交接仍约 16–17 秒，本轮改善集中在入口后的后台收尾与运行长帧，不能称作入口耗时已经显著改善。

UI 窗口按地图、背包、技能、角色、设置每 8 秒依次打开，再全部关闭。`*_on_02` 及诊断/后续样本另含六次受控 HUD 快照重放，服务器状态不变；初版 `baseline_on_01` 没有重放。因此稳定期可对照，含重放的窗口阶段单列，不能混算。

原版 `baseline_on_02` 与最终 `optimized_on_03` 的全部五个窗口打开阶段（均含相同快照重放）：p95 201.145 → 82.211ms，最大帧 331.554 → 94.471ms，1% low 3.02 → 10.64 FPS。这个阶段每次只有约 8 秒，不外推长时间分布。

- 原版/修复同相机图像对照：中、远、细节的 base/candidate 共六图逐像素一致；近景两图平均每通道差小于 0.000005/255。报告 `proxy_image_comparison.json`。本轮不改模型资产、LOD 索引或画质参数。
- `baseline_on_01` 首次打开角色窗口出现 3110.751ms 帧；诊断及随后样本没有再次出现该量级。首次窗口同步构建本身仍约 100ms，尚未解决；没有把缓存后的未复现写成修复。

失败样本也保留：`refresh_scope_after` 的动态调用 Array 元素类型错误（引擎退出码仍为 0），`optimized_on_02` 的未创建角色窗口缺少 `gold_label` 元数据。两项均修复；后续执行器把日志中的引擎/脚本错误也判失败，不能只看进程退出码。
