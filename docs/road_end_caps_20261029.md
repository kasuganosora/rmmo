# 道路独立端头支持平头（2026-10-29）

用户指出公会台阶前的道路末端是圆弧，希望支持平头。实现为每条道路两端分别选择圆头或平头，沿节点横截面收口；不是为截图中的某一块路面做一次性裁切。已有地图省略字段时保持原来的圆头，已连接路口不被截断。

## 交付与操作

- 城镇布局的道路线段属性增加“起点端头”“终点端头”。平头对应 `from` / `to`，应用后沿端点的道路宽度截面结束；节点位置仍由用户编辑。
- 3D MCP `update_road_graph.edges[]` 同步接受 `cap_start/cap_end: round|flat`，复用既有 schema、共享业务操作、原子事务和保护。旧二维入口仍下线。
- 已开启 `kerb_enabled` 时，改变端头会同笔重建铺面和连续路缘。否则沿现有流程重新预览并应用铺面。碰撞使用实际几何，无圆弧的不可见残留。
- 同层交叉拆分与住宅接路拆分都只在原来的外端点保留样式；内部新路口恢复默认样式。
- 保存重开、撤销重做、稳定分块身份与派生合批均保留。没有修改用户的正式地图，正式台阶位置的布景仍由该地图编辑操作决定。

## 代码范围

`city_layout.gd` 定义可选字段；`city_panel.gd` 显示选项；`mcp_schema.gd` 同步工具说明。`road_plan.gd` 只在独立端点为平头时跳过圆形端帽，继续复用已有路段横截面和路口填充。`road_intersections.gd`、`residential_placement_tools.gd` 处理拆分继承。没有新材质、纹理、模型导入格式或独立路缘实体。
