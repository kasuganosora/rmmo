# 古铜旗幡路灯预制件 · 2026-10-05

用户要求在性能优化期间，另开 subagent，照资料在 Blender 制作新截图中的路灯。后续用户追加了随游戏风场飘动、独立换旗及替换图案。本版已接入 3D 编辑器和 MCP 并发布到默认素材库；尚未在正式城镇批量部署。

## 参考与结构取舍

- 用户原图：[旗幡路灯](references/banner_streetlamp_20261005/user_reference.png)。细长深棕金属杆、套环与宽脚座，上部为尖帽分格玻璃灯笼；柱侧有卷曲铁艺和水平横杆，红底金边的尖底竖旗通过挂环悬挂。字幕、背景房屋和人物不是本资产内容。
- 用户后续指出[两处接口未对齐](references/banner_streetlamp_20261005/joint_correction.png)，并要求灯内改为菱形幽蓝魔法石；[夜间参考](references/banner_streetlamp_20261005/blue_crystal_light.png)采用蓝白亮芯、青蓝外晕，不保留蜡烛和火焰。用户随后要求适当减面，最终版本包含这三项修正。
- 原有城镇资料入口：[逐图观察](medieval_town_visual_references.md)，特别是临河商街、桥头街道与招牌支撑关系。
- [Historic England：Broad Walk 灯柱，1259390](https://historicengland.org.uk/listing/the-list/list-entry/1259390)：采用其八角底座、分段渐细灯杆、横杆及分格玻璃灯笼之间的构造关系。
- [Historic England：Minster 灯柱，1245058](https://historicengland.org.uk/listing/the-list/list-entry/1245058)：参考其柱脚、装饰套环和曲线灯架的明确连接。两处均为近代灯柱资料，**不能据此称作真实中世纪路灯复原**。本件是遵循用户动画参考的幻想城镇道具，金色双环图案为原创抽象装饰。

承重路径为八角锚板 → 渐细柱脚 → 金属主杆 → 套环/灯笼托座；旗杆横臂有下斜撑与卷曲辅助撑，挂环真正跨在横杆上。上卷花从横杆套筒连续上卷，没有旧直段接螺旋的折返尖角。灯笼四边托盘、檐板和雨帽统一朝向，与四角竖框对齐；框脚嵌入托盘，玻璃与下压条贴合。八棱菱形魔法石由底部锥形金属座承托，内部另有较小的实体菱形晶芯。旗面是有轻微折褶和厚度的网格，金边抬离布面避免共面闪烁。

尺寸为游戏自定，不来自照片测量：总高 **4.098 m**，杆脚原点在地面；包围尺寸约 **1.299 × 4.098 × 0.417 m**。柱脚半径 0.19 m，主杆半径约 0.04–0.052 m，旗宽约 0.67 m、高 1.14 m。旗底约 1.695 m，侧臂最远约 1.09 m；后续摆放须让旗幡朝建筑退界空间，不覆盖角色必经通道，建议柱心离通道边界至少 1.15 m。第三人称/VR 下的实际密集街道美术与通行验收留待部署时进行。

## 静态预制件与可选夜间场景的边界（早期记录）

以下是正式接入之前的状态；当前游戏及编辑器的接入结果见文末「正式昼夜接入与旗帜朝向修正」。

**原生地图资源库保存的是带独立旗帜槽的 GLB，不带自定义灯光脚本。** `world_document` 识别 Blender 明确标记的布料槽，接入换旗和游戏风场；布料不产生刚性碰撞，金属件沿用现有模型碰撞处理。换旗为新增的 3D UI/MCP 共用业务操作。

独立 `banner_streetlamp.tscn` 提供可选夜间表现，使用两只圆柱碰撞体替代装饰细节碰撞。`BannerStreetlamp.update_group(lamps, observer_position, hours, remaining_budget)` 接收集中控制者传入的灯具列表、观察者位置、时钟与**剩余共享预算**；`update_from_weather` 可读取现有天气时钟一次后集中更新。仅复用现有壁灯的夜间判定（20:00–06:00），没有复用火焰模型；蜡烛、灯芯、`NightFlame`/`FLAME_POSITION` 均已移除。

- 默认预算为 **0**，不会自行打开实时灯。
- 每次集中更新最多启用 2 盏最近的 28 m 内灯；60 m 外晶石恢复非发光材质，隐藏/卸载灯具不发光。
- 日间仍可见蓝色实体菱形石，但无自发光或动态灯。用户追加“光晕加一点”后，夜间外晶面青蓝自发光由 1.8 调至 2.5，内部菱形晶芯蓝白自发光由 4.0 调至 4.8；保留清楚的晶体轮廓，近场点光青蓝色。未增加网格、光源或全屏光效步骤，未改变全局环境光晕设置。此款灯的夜间材质仅两份共享资源；池按原材质 Resource 身份缓存，避免同名异材质串用。晶石实例及昼夜状态不变时直接返回，不反复设置材质覆盖，也不每次更新创建材质。

- **尚未把街灯类型接入正式城镇的照明管理器，也未批量部署。** 本次不会把独立场景夜间测试误报为原生地图预制件已自动昼夜点亮。

## 旗帜独立更换与游戏风场

- Blender 输出 `BannerCloth`，其中红布、金边、纹章一起变形；灯杆、挂环、支架、玻璃、晶石独立保持刚性。节点用 `extras.rmmo_banner_slot=true` 显式标记，不能凭模型文件名猜测柔性。
- 接入现有 `weather_controller → wind_runtime → wind_material`，使用真实风速、方向和时间；顶部固定、摆幅 0.45 m、刚度 0.22，并沿用遮挡检测和 90 m 接收范围。无风时静止；没有每盏灯的 CPU 布料模拟。
- 选中单盏或多盏新版路灯，检查器中出现「路灯旗帜」：可选尖尾/长方/燕尾；「整面换旗…」选择完整图片；「只换图案…」选择透明 PNG，保留布料底色；可去图案、恢复原版红金旗帜或关闭受风。图片自动导入外部资源目录，之后保存地图即可。

## 正式昼夜接入与旗帜朝向修正（2026-10-05，首轮接入记录）

下述两盏近灯预算已被用户否决，当前规则见文末「夜间整街自动点亮」。

用户实测发现夜间没有亮灯，且道路侧看到红布背面。原因是地图放置 GLB，而早期夜间控制仅位于独立 TSCN；原版金色图案面是模型本地 **+Z**，原布置方向相反。

- 游戏和 3D 编辑器现在通过同一个 `weather_controller → streetlamp_lights` 控制器接入正式天气时钟，20:00–06:00 开启；昼夜验收道具、环境面板和 MCP `set_environment` 都驱动同一效果。
- 显式旗帜槽对应的 `ArcaneCrystal` 获得灯具标记，流式加载重建 MeshInstance 时恢复注册，旧几何缓存按生成器版本失效。无需替换每盏 GLB，也不把灯光写成地图对象。
- 夜间晶体外层/内芯自发光分别为 2.5/4.8，65 米内增加轻微蓝色面向相机光晕，光晕保留深度测试。无需开启全屏 bloom；隐藏或卸载的灯具自动熄灭。
