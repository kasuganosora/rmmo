## 成本与复现

正式库发布中保留了一次住宅导入的失败收据：源/native 均已成功生成，旧单道具发布脚本却把 `model_building` 描述经 JSON 保存后的 int/float 类型差异判为独立修改。新增专用适配只允许该描述内数值的 JSON 舍入误差，仍严格比较键、文本、身份和其他条目字段；真实坐标、SHA、键变动的拒绝自检通过。随后从原失败收据恢复命名，未覆盖旧证据或重复导入不同资源。

首轮正式 HTTP 验收也保留在 `formal_http`：住宅的半开状态实际已保存为 `model_building_states.River_entrance=0.5`，旧公会验收脚本却只读 `model_component_states`，造成一次误报。已按生产模型类型选择状态字段，并增加重开后实际组件 `open` 值的检查；没有改动编辑器保存实现或模型字节。新结果记录在 `formal_http_v2`，不覆盖首轮。

未做强制减面或新增 LOD。院门曲线与叠层柱头、陶罐口沿/耳柄保留平滑轮廓；旗帜保留风场所需分段；住宅保留独立楼层/屋顶/门。此次减少旧拱廊体积是参考修正，不能将不同形体的面数差称为无损性能优化。当前唯一/实例三角面相同（每件一个实例），共享纹理以 SHA 去重计预算；不按实例数重复计算贴图。未测 RSS/VRAM、整城 FPS 或缓存峰值。
