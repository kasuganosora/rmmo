# 建筑分阶段入场与地形远景（2026-10-17）

按用户指定，把剩余清单的第 4、5 项提到 W0-R／其余运行时发布之前。在 `codex/editor-reliability` 隔离 worktree 实施，基线为 `d1121df18039605a19a7f4aeedc9bd05b0e7b989`。本批不打开、保存或切换场景搭建会话的地图／工作目录，不接管其进程。GPU 使用 `run_godot_background.py` 的不激活独立桌面；夹具、GLB、native、截图和运行缓存全部放外部 `rmmo_runtime`。

## 已实现的范围

### 已验证建筑分阶段就绪

`entry_stage_policy.gd` 先让本地权威从完整作者目录确认建筑语义。全部建筑成员、入口和归属均可证明，且不存在未知体积时，选择 `staged`。否则保持完整等待并返回具体原因；既有地图不要求重新保存。没有把所有未注解导入物默认当成户外，因此含未分类模型的混合地图可能保守回退整图。

分阶段路径保留成员闭包、结构／姿态版本、活动件状态序列、真实碰撞发布、落点胶囊和目标首帧，之后才开放输入。寻路可以继续后台准备，键盘移动继续经过物理和建筑穿越屏障。`building_readiness_enabled` 仍作为测试强制开关；正常路径由自动策略决定。

风动的准备／接入状态同时提供 UI／HTTP 查询，但 `wind_background_enabled=false` 保持候选关闭：它只绑定已经预热的 shader 变体，新进入视野的未知变体要等后续遮挡准备，不能让这种静态等待成为默认行为。默认保留已有风动接入；风动后台的补齐不由建筑提前入场的通过代替，也不把冷 shader 提交偷偷转移到行走阶段。

初次入场的建筑准备与角色／导航／HUD 准备并行，最后汇合完整校验。自动选择刚验证过的目录可由同一个不可变运行根和相同源版本复用，避免建立两次；直接合同调用默认仍重新注册，根或版本不同则重建。跨图失败先恢复源策略并重新授权原位置；切到完整等待地图时取消旧建筑票据，失败的目标票据也立即释放。

游戏 HUD 与 `playtest_state.preparation` 共用 `World3D.preparation_state()`：分别给出策略、可操作状态、寻路 ready／preparing／failed 和风动接入状态。寻路尚未完成时明确提示“可用键盘移动；点击寻路准备中”。试玩使用刚保存的临时副本 SHA，修复此前副本缺少版本标识导致无法采用该合同的问题。未增加工具参数，不恢复已停用二维适配器。

### 地形几何与材质远景

`terrain_render_lod.gd` 在现有后台地面几何批次中建立三档索引；密集常规高度场可单块生成，也可在原空间批次内组合。保留原顶点、法线、切线、UV、材质、源网格和精确碰撞。仅渲染索引改变，作者 UUID、选择、保护、撤销、保存与已有地形增量失效流程保持。

每个外边界保留原网格的全部线段，内部不整除步长的窄条也保留必要接点。各档共用原边界，独立选择 LOD 不引入新的 T 接缝。误差上界取原高度范围与“相对同一仿射平面的最大偏差的两倍”的较小值；两种三角剖分都在此平面的同一包络内。屏幕误差选择使用更保守的阈值，镜头距批次包围盒 160 米以内强制原网格。不同格距原本存在的法线／材质邻域差异没有被宣称修复。

真实洞格、手刷表面及不规则／分裂顶点拓扑保持完整回退；底床与切边不简化。运行时只遍历登记过的地形 LOD 弱引用，不每次扫描所有建筑批次；删除、重建与 clear 同步移除登记。编辑器视图保持精确网格，运行与 UI 试玩共用远景策略。

`river_terrain.gdshader` 仅把 160–320 米间的微法线强度平滑降到零，到达远端后跳过对应法线采样；基础、沙、岩、土与两类覆盖层共用该逻辑。颜色、覆盖、高度混合、粗糙度、金属、AO、湿润变暗与水线继续使用原逻辑。没有压缩纹理，也不宣称减少纹理驻留。相机放大及陡坡的具体效果以误差阈值和同镜头验收为边界，不承诺任意镜头无损。

### 静态透明植被：完成试验，默认保留关闭

新增独立候选 `static_scatter_instances_enabled=false`。开启后随机散布与成行散布可复用相同静态单网格 alpha-scissor 实例；原材质、纹理、mip、阴影与源 LOD 保留。混合透明、billboard、骨骼／动画、可编辑活动组件、逐实例可见距离和风动继续排除。补查模型自身 `rmmo_wind`，不能仅看记录覆盖是否关闭风动。

真实 GPU 显示引擎已自动实例化这些来源：四个固定镜头的调用数分别为 **2→2、2→2、3→2、2→2**，细节镜头的提交三角形反而由 **684→1548**。画面完全一致，但粗包围盒扩大了可见提交量，不能用节点变少宣布整体提速，因此没有默认启用。本次不重做已交付的植被 LOD／风场，也不把这个待测候选记成正式默认优化。

## 验证与测量口径

原始结果、源码 LF SHA、运行资源 SHA、截图压缩记录与完整检查统计以 [证据索引](../review_artifacts/staged_far_20261017/evidence.json) 为准。GPU 固定 Godot 4.7.2 `ed1daf0bf`、Forward+、Vulkan、RX 7900 XTX；性能工作串行进行。

最终 **15 组回归通过**，日志可见 **687 条 PASS、0 功能失败**；仅在汇总行记录的逻辑比较不混入逐条 PASS 数。另保留 8 次完整入口对照、20 个经实际查看或相同 SHA 复核的 Q90 WebP，以及 2524 项脚本／shader／工具的 LF 源身份。

- 自动策略真实入口：完整跨区块住宅、实际导航工作被暂停但未伪造 ready、HUD 与合同状态、释放后的真实导航完成、未知目录完整等待、跨图失败恢复、完整等待到分阶段切换及 20 轮抢占取消／重访；退出后 loader、烘焙和 drainer 清零。保存文件 SHA 不变。
- 当前 3D HTTP：工具发现、非法参数无副作用、UI 应用、撤销重做、保存重开、`playtest_state` 的实际 pending／ready、同图和跨图、遮挡中退出、无法绘制的视口不放行。导航与风动不是 `phase=running` 的同义词。
- 地形 CPU：16／31／32／64 网格各档的覆盖、绕序、全部外边界、无内部 T 接缝、实际采样误差、洞口及非网格回退，原数组字节保持。
- 地形 GPU：真实 native 保存重开、worker 数组与实际 renderer LOD buffer 对账、近中远／细节同镜头、实际地面射线、陡岸和洞口保留。额外 LOD 索引字节与后台 CPU 准备开销独立统计，不能把提交三角形下降直接当整城帧率提升。
- 静态 cutout 候选：真实外部 GLB 导入、native 重开、UI／HTTP 随机散布和单笔撤销重做、保存重开、同镜头 alpha 叶缘与投影；无风版本作固定 A/B，风动来源明确排除。

入口对照采用同一个临时地图、相同角色与视口，多进程、交错 A/B；A 为关闭自动分阶段与后台服务的旧路径控制，B 为生产自动策略。初始化、真实加载画面、实际首帧和输入恢复均计入。完整原始值及重复 A/A 波动保留，不从“后台”字样推导加载收益，也不把合同观察器 `entry_readiness_shadow` 当成真实授权证据。首次串行实现的回退原始记录保留在外部 `entry_before_overlap/`。

入口计时使用最终默认开关及提示文字，风动后台在 A/B 双方均关闭；之后补了等待物理帧时销毁初始世界的取消保护，不改变正常准备顺序与门槛，另用实际销毁夹具复验。未清除 OS 页缓存或 GPU 驱动缓存，不将该组称作物理冷启动。透明植被候选保留原 mesh LOD buffer，但 MultiMesh 按共同包围盒选择等级，并非逐源独立 LOD；这也是默认保持关闭的边界。

开发迭代没有并入最终通过数：首轮地形夹具各落在独立批次格，暴露单块未生成 LOD；粗误差估计过保守，真实 renderer 没有选择降档，改为有证明的平面包络；近景首次检查的一处输出通道相差 1 LSB，保留为量化差异并实际看图，没有改称严格无损；首次试玩缺源版本而走完整等待，已补真实副本 SHA；通用 GLB 导出器的 `GODOT_single_root` 声明被保守 native 目录拒绝，测试保留原始导出，另输出相同标准 glTF 图／buffer 后重新导入，没有放宽生产校验。静态透明实例未证明通用收益，风动后台的未知变体不能及时补齐，均保持关闭。退出诊断中的对象警告另行保留，不用“检查通过”覆盖。

部分控制／强制候选进程退出时出现 1 个 ObjectDB 警告；两组均有，默认自动策略的最终 verbose 复跑未复现。真实 world、loader、导航烘焙和 drainer 清理检查通过，仍不据此宣称整个进程没有泄漏。verbose 中测试角色 glTF 的 packed buffer stride 提示另行计数，未修改正式角色资产。所有警告保留在日志和证据索引。

## 回退及剩余边界

关闭 `automatic_staged_entry_enabled` 与 `navigation_background_enabled` 可回到原入口路径；导航、风动后台开关及强制建筑候选仍可分别对照。`terrain_render_lod.enabled=false` 保留基准索引，shader 的 `far_detail_enabled=false` 恢复原微法线采样。无需迁移或重写地图。透明植被扩展与风动后台候选默认关闭。

未知／不完整建筑、动态对象、全部导入层级的通用远景简化，以及所有 W0/W1/W2/W3 其余专项没有由本批自动完成。植被扩展须先取得有代表性的端到端收益，再考虑默认启用。统一队列的下一优先范围见 [统一执行顺序](seamless_streaming_optimization_plan_20261014.md#统一执行顺序)。
