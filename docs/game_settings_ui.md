# 游戏设置界面

仅调整游戏 HUD 的设置窗口；内容编辑器的界面、功能和 MCP 不变。

## 布局

- 窗口为 560×480，五个主标签页保持原有入口。标题直接置于窗口底色上，没有内层标题框；标签页用细下划线表示选中状态。
- 画面按显示、性能、界面分组。声音按整体音量和分类音量分组，滑条与百分比列对齐。
- 游戏页拆成显示、操作、界面三个子页。显示页包含名称、血条、战斗信息和获得提示；操作页包含移动、挂机提醒、拾取和药水；界面页包含 HUD、镜头、快捷栏和窗口位置。
- 按键采用双列表格，快捷栏的固定按键说明放在表格后。切换标签或关闭窗口会取消待绑定状态，Esc 保留原按键。
- 系统入口归入社交与玩法、角色与会话、工具，保留已有按钮及其回调。
- 底部固定显示自动保存提示与“恢复全部默认”；该按钮原本就是全局重置，现在明确标注作用范围。系统入口页不显示该重置按钮。
- 自动拾取关闭时，其类型选项禁用；自动药水关闭时，其阈值禁用。开启后原地恢复编辑，无布局跳动。
- 设置面板使用不透明背景，避免后面的快捷栏和聊天内容干扰阅读。

## emil-design-eng 复核

| Before | After | Why |
| --- | --- | --- |
| 标题又套一个金属描边矩形 | 标题与窗口融为一体，只保留窗口外边界 | 减少重复框线与厚重感 |
| 主标签和子标签均为凸起框按钮 | 文字标签、选中下划线与轻背景 | 用清晰状态建立层级 |
| 游戏设置混在单条长列表 | 按显示、操作、界面分组 | 按用途查找，无需逐项翻找 |
| 标签宽度不一致，音量数字拥挤 | 统一表单列宽、行高、间距和独立百分比列 | 提高扫读与操作稳定性 |
| 恢复默认夹在各页内容中 | 固定底栏，明确“恢复全部默认” | 滚动时入口稳定、语义清楚 |
| 恢复默认直接覆盖设置 | 窗口内说明恢复范围，明确确认/取消，Esc 优先取消 | 防止误触；关闭窗口后不保留待确认状态 |
| 大段按键说明挤占首屏 | 双列按键表，固定快捷栏说明移到下方 | 优先呈现可编辑内容 |
| 设置窗口透出后面的图标与文字 | 独立不透明底板 | 保证文字可读性 |
| 等待绑定时切换页可能继续吞键 | 切页、关窗和 Esc 均取消绑定 | 防止模式残留 |

高频切页、勾选和键盘操作即时响应，没有引入过渡动画。

## 验收

`tools/test_settings_layout.gd`：真实鼠标与键盘事件验证标签切换、勾选、滑条、药水阈值、按键保存/取消、固定底栏、全部系统入口保留，以及 900×700 / 130% 缩放下的布局和标题拖动/关闭。测试禁用玩家设置写入。

`tools/test_game_settings.gd`：原有设置存取、声音总线和 HUD 功能回归。

本轮设置界面 42 项检查通过；共享拖动逻辑使用事件坐标转换，避免读取失效的系统指针位置。快捷栏 54 项交互回归与 HUD 拖动测试均通过。

GPU 必须通过 `tools/run_godot_background.py` 在私有桌面执行。验收截图与日志在外部运行目录 `review_artifacts/settings/`，包括 `video_detail.png`、`audio_detail.png`、`game_display_detail.png`、`game_assist_detail.png`、`game_hud_detail.png`、`keys_detail.png` 与 `system_detail.png`。
