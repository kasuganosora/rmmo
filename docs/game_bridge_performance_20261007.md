## 已定位并处理

- 小地图覆盖范围变化时重新提交全部可见地物的填充与轮廓。在草丛密集桥岸，单次静态层绘制准备曾达到约 70 毫秒。现在在加载期间预先记录每个凸形投影的 CanvasItem 绘制指令，移动只更新可见集合和父变换；缩放更新线宽，地图替换、版本变化和退出时重建或释放。原始顺序、颜色、透明度、抗锯齿和地图投影不变。薄草叶投影改用单次索引三角扇，避免原耳切三角化失败。
- 首次遇到不同材质路灯时生成夜间材质，即使白天也会触发。两个诊断样本分别约 151 和 225 毫秒。现在从完整驻留库预先准备材质，首次进入和切图均在加载遮罩下完成。没有删除灯具、关闭夜间发光或缩减灯光范围。
- 风场距离扫描改为每批取相机/World3D、平方距离比较，保留实例位姿、范围和包围盒的实时读取。单独优化曾在 1500 对象 headless 合成对照中测得 3.283 → 2.863 毫秒；后续为分片维护 active 索引增加了工作，最新合成对照约 2.95 → 2.99 毫秒，不再把早期 13% 收益当作最终结果。
- 周期风场扫描和清理改为每渲染帧一次、约 2 毫秒检查点预算，避免把整轮绑定、避风射线和失效释放集中在一个物理帧。已有风动继续更新，新绑定当片应用当前风时间；公共 `refresh()` 仍同步，关闭和退出取消队列并恢复原材质。0.35 秒从扫描启动计时；一轮超过该时间则完成后尽快开启下一轮，不保证每个对象恰好每 0.35 秒更新。单个绑定、射线和释放不可拆，实际片段仍可能超预算。
