# 3D 地图编辑器：物件变换与功能缺口

2026-10-01。本轮处理的是地图物件（原消息的“发型”为笔误），包括基础方块和导入 GLB；不修改角色发型系统。

## 已实现

- 选择物件后，W 移动、R 旋转、T 缩放。红 X、绿 Y、蓝 Z；移动用箭头，旋转用圆环，缩放用方块手柄。
- 移动的中心方块沿 XZ 地面平面拖动，Y 箭头升降；缩放的中心方块等比缩放，轴手柄单轴缩放。缩放限制为正值，避免反转或零尺寸碰撞体。
- L 或“世界轴／局部轴”切换移动、旋转的坐标空间。缩放始终沿物件局部轴，不产生剪切。
- 位置、角度和缩放各自设置吸附，可关闭；按住 Alt 拖动临时忽略吸附。轴向移动按拖动距离吸附，保持其他坐标不变；中心移动沿用 XZ 网格吸附。
- 一次拖动只产生一步撤销，松手在侧栏也会提交；Esc 取消拖动，保持原变换与重做历史。点击和小于 3 像素的抖动不产生修改。失去应用焦点时结束拖动。
- Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做；新修改清除旧重做分支。菜单和工具栏均有入口。
- 拖动和数值变换只更新选中物件及其拾取碰撞体，不重建整张地图。导入模型沿用原资源；保存仍从文档记录重新生成 glTF。
- Esc 空闲时先取消选择；无选择时返回登录，有未保存修改会提示保存、放弃或取消。“文件”菜单也可返回登录。
- 按用户追加需求，两种 3D 自动瓦片均已接入基础版：墙／道路自动连接，草地／泥土／浅水的边角与材质过渡。使用方法与边界见 [world_editor_autotiles.md](world_editor_autotiles.md)。

右键旋转视角、中键平移、滚轮缩放、F 聚焦、方向键及 PageUp/PageDown 微调、Q/E 转向、Ctrl+D 复制、Delete 删除继续保留。沿视线重叠的移动/缩放轴不显示可拖手柄，转动视角或使用数值栏即可编辑该轴。

## 物件列表、组合与预制件（2026-10-01 追加）

左侧新增“物件”页，按组合显示场景实例。可以搜索名称／ID／类型、编辑名称、双击聚焦；“显示”和“锁定”复选框支持整组操作。隐藏只作用于编辑视图和拾取，保存后的游戏场景仍保留这些物件；锁定会阻止选择、变换、删除和自动瓦片刷除。两种状态与组合名称一起保存，并可撤销。

- 画布 Shift+点选增减选择，Ctrl+A 选中所有可编辑物件。B 切换框选，选取完整落入矩形的物件；Shift+框选追加，Esc 取消矩形。W/R/T 返回变换操作。
- Ctrl+G 成组，Ctrl+Shift+G 解组。在画布点击组合成员会选择整组；在“物件”列表点选子项可以独立编辑。包含隐藏／锁定成员的组合不能通过画布整体选择，先在列表显示并解锁。
- 多选移动共用 XYZ 箭头；旋转绕共同包围盒中心；缩放使用中心方块整体等比缩放，同时改变成员间距和尺寸。多选数值栏显示组合中心、增量旋转和等比倍率。单个物件继续支持局部三轴缩放。当前不支持多选非等比缩放、嵌套组和独立枢轴编辑。
- Ctrl+D、Delete、微调及撤销／重做作用于整份选择。复制组合会重新分配成员和组 ID。自动瓦片参与实际变换或复制时冻结当前形状，变成独立物件；撤销恢复原自动关系。
- “物件”页、“属性”页和“编辑”菜单都有“保存预制件”入口。填写名称并选择资源包后，素材库可以搜索、预览、拖放或连续点击放置该组合。每次放置产生独立、可继续编辑的成员及组 ID，一次放置对应一步撤销。
- 预制件以最低表面为落点，数据保存在资源包 `assets/prefabs/`；引用模型打包进同一资源库，内部用相对路径，整个资源库搬迁后仍能读取。预制件及模型缩略图只在明确保存／导入时生成，浏览仍使用已有的有界缩略图缓存。
- 当前预制件是保存时的快照。修改一个已放置的实例不会自动修改素材库或其他实例；保存新的预制件可复用新版本。场景中的组合为一层，不包含嵌套父子变换。

验证：`test_world3d_prefabs.gd` 检查模型依赖打包、源文件移除、资源库搬迁、身份与内部事件目标重映射、原子库保存冲突、损坏输入、撤销重做、地图重开及运行时加载。`test_world3d_groups_ui.gd` 在独立后台桌面驱动真实鼠标和键盘，检查多选、框选、组合变换、取消、列表锁定／隐藏、保存预制件对话框及重复放置；截图位于工程外 `review_artifacts/editor_groups/`。

## 3D 自动拼接的落地边界

原有 `world3d_rewrite_plan.md` 第 8 节和 P5 已要求墙桥连接规则及 3D 铺设。本轮实现规则驱动的基础套件和编辑闭环，完整 P5 仍未完成。

- **模块连接**：墙、围栏、道路用邻居和连接点选择孤立块、端头、直段、转角、T 形和十字模块，自动转向；添加、擦除、替换后更新受影响邻居。
- **地形过渡**：草地、泥土、水岸需识别四边和对角关系，处理外角、内角、洞和不同材质相接。桥面与桥下、不同高度的表面不能互相误连接；高差还需要独立的坡道／台阶规则。
- **资源定义**：规则集应随工程外资源包保存，指定稳定 ID、版本、单元尺寸、枢轴、连接类别、模型变体与碰撞语义。普通 GLB 不能因外形相似就自动纳入连接。
- **编辑事务**：逻辑格与生成实例身份分开保存；一次笔画连同邻居重算共同撤销／重做；保存重开仍能继续自动拼接。自由移动／缩放自动块时，需要显式脱离规则或整组移动，不能下次补画又跳回原位。
- **验收样例**：一条带转角和 T 口的路、一圈可开缺口的墙、一块带内凹角和洞的地形；重画不叠块，擦除补边，桥上下层互不影响，保存重开、撤销重做及真实碰撞一致。

用户已确认两类都要；墙、道路和三种地形的基础规则已实现和验收，正式外部美术套件与复杂高差留在后续范围。详情见 `world_editor_autotiles.md`。
