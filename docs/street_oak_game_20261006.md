## 几何和材质

原高细节整树展开约 16,607,056 三角面。保留原来的枝条实例和枝序，将相邻、朝向相近的完整叶片局部拟合为叶片网格，分别烘焙颜色、覆盖和切线法线。烘焙时隔离每个局部组，并核对射线命中的组编号，防止把其他层的叶片重复烘入、填实间隙。没有把整根枝条压成一块不透明平面。

首轮发现部分射线命中叶背，导致法线进入错误半球、大片叶片变黑；已校正法线朝向，降低叶面法线强度至 0.25，并恢复薄叶透光。只扩展贴图透明区中的 RGB 和法线颜色，不扩展 alpha。原始烘焙留在 `unprocessed_bake/`，可重复重建。

九组叶片贴图合入一套 3072×3072 颜色/透明及法线图集，各 LOD 共用。运行资源有树皮和叶片两种材质；近景为树干一表面、树冠两表面，中远景为树干和叶片各一表面。木质枝条合并保留共享顶点，避免按面拆点产生平滑断裂。树皮保留已购扫描 PBR；叶面源自此前程序化重建，仍不是 Quixel 原版扫描叶纹。

## 对照与边界

`master_*` / `game_*` 图像锁定同一相机、灯光、曝光，覆盖全树、另一侧、叶枝特写和逆光。这组比较针对 446,280 面的可编辑优化母版；运行导出进一步简化木质主干并合并图集至 388,615 面，另看 `runtime_lod_0.png` 与各距离运行截图。全树、侧面、逆光平均 RGB 绝对差约 2.86、2.28、2.86（0–255）；叶枝特写约 10.19。统计只用于辅助定位差异，不把母版的对照数字冒充最终 GLB 的同条件像素差。

主冠轮廓、自然缺口、主枝位置和总体投影保持接近。叶片网格简化了微观弯曲与厚度，极近距离和掠射角下仍能与实体叶片母版区分；本结果不能标成数学无损或用于树叶微距摄影。中远景用较少完整叶片网格配合覆盖补偿，限定距离使用，不能拿远景档当近景素材。整图植被密度、最终街区光照及角色相机仍需随正式布景验收。

## 复现与验证

顺序为 `build_oak_game.py` → `pad_oak_atlas.py` → `review_oak_game.py` → `export_oak_game.py`。`verify_oak_game.py` 重开优化母版检查参数、505 个实例及贴图打包；`test_oak_game.gd` 使用后台 GPU 桌面和真实 loopback HTTP MCP，在临时目录检查导入、非法调用无副作用、放置、撤销重做、保存重开、LOD、风动和 32 棵树合成场景。最终状态以 `validation.json`、日志及图像共同为准，不以失败数单独掩盖脚本错误。

本轮没有新增编辑器业务能力；UI/MCP 复用现有资源导入、放置、风场和保存操作。未经完整地图测试，不声称任意密度森林或整城帧率已经通过。

最终复查：`authoring_validation.json` 为通过；`validation.json` 的失败数为 0，真实 HTTP 保存/重开通过，最终运行日志无 `ERROR` / `SCRIPT ERROR`，GLB SHA-256 与该记录一致。最初测试暴露的 Windows 材质名非法字符已修复；压力测试改为复制未绑定风材质的原型，避免复制已经派生的 ShaderMaterial 后重复绑定。

32 棵树的合成测试在 RX 7900 XTX、1000×1000、MSAA4/TAA 下测得 GPU 中位约 2.70 ms，可见提交约 210 万三角形、19 次绘制调用。包含场景地面及混合 LOD，未证明整城 FPS 或 VR 性能。该批次复用同一模型与材质，未新增 MultiMesh/地图散布业务。

粗干修订的最终重测也通过：HTTP 保存重开、风动、三档 LOD 和参数母版验证失败数 0，日志无错误。近／中／远三角面为 388,614／80,631／37,719；新的主干减面结果比前版少 1 面，性能量级不变。32 棵合成测试 GPU 中位约 2.76 ms。该结果是下述细枝优化前的历史记录。
