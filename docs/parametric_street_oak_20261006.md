# Blender 参数化街树 · 2026-10-06

后续：用户认可宽冠版本后，已制作保留参数母版的游戏优化候选和三档 LOD，见 [宽冠橡树优化](street_oak_game_20261006.md)。下文保留高细节母版阶段的面数和限制；游戏候选尚未增加到共享库或部署正式地图。

## 文件与使用

母版：`D:/code/rmmo_runtime/art_sources/bridge_street_kit/english_oak_procedural/street_oak_parametric.blend`。

选中 `STREET OAK | editable parameters`，在修改器面板调整原生 Geometry Nodes 输入，不需要启用 Python 自动运行或安装插件。文件内的 `README | STREET OAK` 提供英文参数说明。生成脚本为 `tools/build_blender_parametric_oak.py`；参数和连接验证、三款预设生成脚本为 `tools/verify_blender_parametric_oak.py`。

打开时为单树编辑场景；切换至材质预览或渲染模式查看叶脉和树皮。在顶部场景下拉框选择 `PRESETS | street - courtyard - riverside` 查看三款预设。需要预览风动时把 `Wind (m)` 从 0 调至约 0.03–0.06，再播放时间轴；对比优化时保持它为 0。

| 参数 | 作用与边界 |
| --- | --- |
| Optimized | 原版/简化模块切换；使用完全相同的造型、材质和光照 |
| Height (m) | 以原始冠顶高度为基准缩放，6–13 m；放大的末梢可能略超出名义高度 |
| Crown spread | 冠幅，和主干宽度平滑过渡 |
| Trunk width | 主干粗细，和树冠共同变形，避免接口断开 |
| Leafy branch size | 从原连接点放大带叶细枝，补足原林地树偏疏的问题 |
| Crown lift / Lean | 调整冠部高度分布和倾斜；根部保持原点 |
| Seed / Irregularity | 连续冠形扰动及可选的叶簇筛选；不宣称产生全新的植物学分枝拓扑 |
| Twig retention | 0.85–1.0，按随机种子保留整套带叶细枝；默认 1，不靠删叶取得本次优化数字 |
| Wind (m) | 播放时间轴时的缓慢树体摆动；比较渲染固定为 0 |

三款预设使用同一模板和共享模块，在独立 `PRESETS | street - courtyard - riverside` 场景中比较；不是三种不同树种。预设对象标记为 Blender Asset，可继续修改参数。

## 来源与外观调整

- 原始素材为用户已下载的 [Quixel English Oak](https://www.fab.com/listings/83642c38-7661-4df1-8629-0422e1898d26)。四款 USD 原件保持不变；本轮选择较宽冠的 **C 型**制作参数化母版，未将 A/B/D 全部改成生成器。
- USD 里的 505 个带叶细枝可复用，叶片自带轮廓几何。重新读取 USD 的面角 UV，避免普通导入路径丢失 UV。主干与细枝用同一空间变形函数定位，模块缩放以各自连接点为中心。
- 从高瘦林地比例调整为街边宽冠，并扩大带叶细枝以增加夏季遮荫。默认主冠高度约 9 m 是本项目选定比例，不是参考图测量值，也不是现实树种的固定规格。
- 源包没有贴图。树皮复用项目已购 Fab `4K Realistic Outdoor Materials` 的 `outdoor_bark` 基色/法线；来源记录见该运行材质的 `material.json`。叶片表面为本次重建的程序化颜色变化、微表面和透光材质，**不是 Quixel 原版扫描叶纹**。为每个连通叶片沿主轴建立第二套 `LeafVeinUV`，补主叶脉、侧脉及细微粗糙度差异，原始 UV 保持独立。保留实体叶片轮廓与弯曲，不将其换成方形不透明卡片。
- 参考入口为 `medieval_town_visual_references.md` 中桥头大树与街景生活细节；目标是盛夏绿冠、自然枝干、遮荫层次，不能以“用了写实素材”代替构图验收。

## 优化口径

叶枝模块做 0.01 弧度以内的有限融并，保留 UV 和材质边界；主干另做保守减面。505 份枝叶保留共享实例，只对主骨架实现网格。原模块留在母版引用的源集合中，切换 `Optimized` 可随时比较。

- 展开全部实例的等效三角面：**16,607,056 → 13,314,503，减少约 19.8%**。
- 优化后独立模块合计 **691,453** 三角面。这个数是共享几何量，**不能说整树实际绘制只有 69 万面**。
- 这是 Blender 高细节母版及实例化优化，不是已验收的游戏 LOD。若直接把所有实例展开导出，仍然很重；游戏侧导出、LOD、风场转换和性能需要另行验收。
- 本轮不修改已发布的城镇地图或资源库，也不将 Blender 时间轴风动等同于已接入游戏风场。

## 验证依据

结果位于母版同目录：`optimization_review.json`、`parameter_verification.json`、成对的 `master_*` / `optimized_*` PNG，以及 `three_presets.png`。比较锁定相机、光照、曝光、渲染种子和样本数，覆盖全树、树干近景、逆光和叶枝近景。实际验收结论以完成后的记录为准。

### 本轮自审结果

- 最终文件已压缩保存并在独立 Blender 进程重开验证：2 个场景、3 个可编辑资产预设、2 张已打包树皮贴图，几何节点引用完整；文件约 62.8 MiB。结果见 `package_integrity.json`，参数与预设检查记录 `passed: true`。
- 造型已从高瘦疏冠调整为宽冠夏绿树，形成连续遮荫；保留不规则外缘、可见主枝和局部透光空隙。符合设定的街边阔叶树方向，尚不代表已完成参考镜头的整场布置。
- 四组成对渲染已人工查看，未发现明显的树冠削平、叶簇缺失、主干高光接缝或阴影形状损失。8 位 RGB 平均绝对差：全树 0.088、树干 0.136、逆光 0.088、叶枝 0.132；像素统计仅为辅助，不能等同数学无损。
- 参数复查覆盖默认 505 个实例、7 m 高度、窄冠、种子 81 下 90% 叶簇保留、两个风动帧。505 个模块的连接点与主骨架变形函数的最大偏差约 0.00000101 m。高度/冠幅等常用更新在本机该次后台检查约 0.19–0.23 秒，不代表任意机器或渲染模式的帧率。
- 保留偏差：叶脉是程序化重建，不是原资产扫描纹理；三个预设共用 C 型拓扑，随机种子不生成新的植物学分枝体系；当前仍为高细节 Blender 母版，游戏 LOD 与运行时风动转换未验收。
