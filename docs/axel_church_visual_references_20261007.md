## 建筑体量和入口

- 主体为沿屋脊延伸的长体量，朝镜头的入口端是高耸三角山墙。红橙色鱼鳞状瓦片覆陡坡双坡屋顶，山墙顶有细长金属尖饰。
- 画面左侧为方形石塔，塔冠是四面收尖的瓦屋顶。塔顶尖端被画框截断，不能据此确定总高度；与主楼的前后精确位置及内部连通关系待平面补充。
- 方塔前下方可见较低的双坡附属体量，带窄窗，旁边有拱形侧门；主楼、方塔和低体量应分件建模。
- 主入口为双扇矩形木门，配突出石门罩、门上横窗、两侧壁灯与浅台阶；入口两旁各有窄窗。上方山墙为中高、两侧低的三扇竖向尖拱彩窗。
- 右侧还有较低的红瓦建筑，带烟囱、老虎窗及上下层窗。单张图不能确认它属于教会附楼还是相邻建筑，暂不并入教会主体。

## 材质和构件

| 构件 | 画面依据与制作约束 |
| --- | --- |
| 墙体 | 浅米灰石块、错缝铺砌；柱状竖向收边和水平檐线独立表达 |
| 屋面 | 红橙瓦、细小重叠轮廓，日落暖光不直接烘进基础色 |
| 彩窗 | 绿、青蓝、浅色几何拼片，深色分格；塔窗及山墙窗使用尖拱外形，低处小窗以原图矩形轮廓为准 |
| 塔身 | 方形截面、水平分段线脚、角部竖向加厚构件，窗嵌入墙体；不套用告警塔的圆形塔冠 |
| 场地 | 石铺道路，周边草地、低灌木、窄冠绿植和大冠阔叶树；不将植物遮挡处误做破损墙体 |

## 后续建模待定项

建筑尺寸、层数与楼板位置、内部大厅、祭坛、楼梯、塔内通路和钟体均需另行规划；本图没有展示塔内钟体。不得根据画面暖黄色推定全部金属为黄金，也不从字幕推定教会教派或名称。后续结构设计先核对现实教堂平剖面，再标注为第三人称通行所作的尺寸调整。
