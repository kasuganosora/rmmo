# 房屋局部外观与石砌构件（2026-10-07）

用户要求补圆形山墙窗及石砌门窗框，房屋允许手动换墙面材质、单独替换某扇窗。此前每栋一种窗型继续约束自动生成；本次明确的手工替换是例外。

## 使用与范围

- 墙面：使用已有面材质工具拾取墙面，再选择材质。已烘焙房屋现在也可刷面、恢复原材质；一次针对一个连通平面，内外面分别操作。锁定、隐藏和楼层隔离保护保留。
- 单窗：建筑面板选择已有建筑，在门窗开合区下方选具体窗口及横格／十字斜撑／菱格，点击“替换这一扇窗口”。双扇窗一起替换；保留固定外框、窗洞尺寸、原铰链硬件和开合状态，以及其他窗口、墙面材质。
- 构件库：“建筑构件”新增石砌圆形山墙窗、方窗石砌窗套、圆拱石砌门套。作为独立模型安装在真实洞口；构件不会自动在墙上开洞。

单窗操作不能将方形洞口变成圆窗，也不替换烘焙墙中的固定外框。已单面刷材质的活动窗扇须先恢复其面材质才能换样式，以免丢失自定义刷面目标；墙面已刷材质不受此限制。无法可靠识别材质的非标准窗拒绝替换。已运行的旧编辑器需重新打开加载新面板和工具。

## 现实参考与尺寸

- [Historic England：Southwick Hall](https://historicengland.org.uk/listing/the-list/list-entry/1040240) 记录山墙顶圆窗、石窗套、窗棂及拱门。该建筑存在多个年代增改，仅借鉴构造，不宣称历史复原。
- [National Trust：MNA143421](https://heritagerecords.nationaltrust.org.uk/HBSMR/MonRecord.aspx?skin=printerfriendly&uid=MNA143421) 记录石边框、窗棂与过梁。
- 使用现有已购石灰岩扫描贴图、旧木 PBR。径向拱石、石缝、出挑窗台、内缩玻璃均为实体几何。
- 圆窗石圈净径 1.12 m／外径 1.50 m；方窗净洞 0.95 × 1.35 m；圆拱门净宽 1.15 m／拱顶净高 2.475 m。尺寸为项目视觉与通行空间设计值，非文保实测数据。
- 门套贯通；圆窗为固定玻璃构件，无开合行为。模型放置不自动改造墙体。
