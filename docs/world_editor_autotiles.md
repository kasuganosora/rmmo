# 3D 自动瓦片：模块连接与地形过渡

2026-10-01：按用户要求，两类功能均进入地图编辑器。当前使用程序生成的基础 3D 模块，属于可编辑、可保存、可在游戏地图加载的功能版本；未替代正式美术套件。

第二批已加入高台 / 悬崖、楼梯、连片屋顶、桥栏杆和自定义 GLB 套件，操作与清单格式见 [world_editor_height_terrain.md](world_editor_height_terrain.md)。

## 使用

在素材库选择带“自动”的道路、墙、草地、泥土或浅水／水岸。工具栏出现“自动拼接”，可设置 1 / 2 / 4 / 8 m 格宽和地形表面／墙底高度。

左键连续涂画；快速移动也会补齐中间格子。Shift+左键或“擦除”开关删除当前类型、格宽和高度的格子，邻居实时补边。重复涂同一种格子不叠模型；草、土、水在同一格互相替换并保留实例 ID。道路、墙和地形属于不同占位类别，可以叠在同一位置，道路表面比地形高 0.06 m。

黄色轮廓表示落点，擦除为红色。高度来自工具栏，不会因命中刚画的墙顶而不断往上堆；不同高度、格宽独立计算连接。不同格宽混用时不自动重采样已有格子。

松手提交整笔（在侧栏松手也有效）；Esc 取消整笔；Ctrl+Z / Ctrl+Y 撤销重做，连同邻居变化一起恢复。未改变任何格子的笔画不占历史。应用失焦时结束笔画。单次鼠标跳跃超过 1024 格会提示缩小范围。

自动块可以被 W/R/T 或属性栏自由变换；一旦确实提交变换，就保留当前形状并脱离自动网格，旧位置的邻居同步重算。属性栏明确显示此状态；撤销恢复原连接。Ctrl+D 的副本也是独立物件。Delete 删除自动块时会修复相邻格子。

## 实现

- `auto_tile_rules.gd` 管理 `tile3d` 版本、类型、逻辑坐标、格宽、高度、附着状态和邻接。墙／道路的四向 16 种状态产生独立、端头、直段、转角、T 形、十字；地形规范化对角掩码，有 47 种有效边角邻接。
- `auto_tile_mesh.gd` 生成共享的单位网格。墙／道路按连接方向组合实际几何，内侧空缺保留；草／土／浅水读取八邻域，以细分顶点色连续过渡，水陆之间产生沙岸色带。对角邻居参与内凹角、外角和洞边缘的过渡。网格缓存最多 128 项。
- `auto_tile_stroke.gd` 每笔建立格子索引，用四连通路径补齐鼠标经过的格子，只重算变化格周边。编辑器局部刷新对应视图和拾取碰撞体，保留其他节点。一次事务保存逻辑格与邻接变化。
- 地图仍由 `WorldDocument` 保存。完整逻辑格写进 glTF records，同时导出真实网格与顶点色；编辑器和运行时记录加载器使用同一网格生成器。读取时检查规则元数据；普通旧地图不受影响。
- 拾取与运行时碰撞均采用生成网格，墙角不会被整块包围盒填满；变换不修改共享网格，而以物件变换矩阵更新尺寸。

几何使用 Godot 的三角形正面约定，参见 [SurfaceTool 官方文档](https://docs.godotengine.org/en/4.5/classes/class_surfacetool.html)。颜色写入线性顶点色，导出后仍保留过渡。

## 验证与当前限制

两类自动瓦片都支持通过当前 3D MCP 的 `paint_auto_tiles` 连续绘制/擦除，复用同一笔画事务和邻接规则，见 [MCP 文档](world_editor_mcp.md)。

`test_world3d_autotile.gd` 检查两类连接规则、47 种地形邻域、负坐标、快速拖画、重复笔画、替换保留 ID、擦除、取消、撤销重做、楼层隔离、自由变换脱离、跨块颜色接缝、保存重开、导出颜色、运行时加载和向上碰撞面。

`test_world3d_autotile_ui.gd` 在独立后台桌面驱动真实编辑器鼠标，检查快速道路拖画、转角／T 口、Shift 擦除、Esc 取消、自动块自由变换、墙内角拾取、高度隔离、保存重开和 1024 像素布局；截图在工程外 `review_artifacts/editor_transform/autotile_*.png`。

内置墙、道路和高差模块为基础造型；可用专用 GLB 套件替换。内置平地仍使用连续颜色过渡，不包含动态水面、深水／游泳、任意悬崖雕刻、自动测量楼梯高差或桥墩。浅水按可通行地面处理。普通 GLB 导入不等于自动套件，必须提供通过邻接覆盖校验的套件清单。

没有修改用户现有地图或角色资源。截图使用临时样例文档，测试结束清理，不能把它当正式城镇。
