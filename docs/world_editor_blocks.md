# 闭合街区、临街地块与批量房屋

2026-10-02，本轮新增四项当前 3D MCP 工具，该批工具总数为 88；后续[植被散布](world_editor_vegetation.md)批次增至 92。入口位于「城镇布局 → 街区围合、临街地块与房屋」。房屋由编辑器即时生成，沿用已有参数化外观、室内、活动门窗、楼梯和整栋编辑能力，不向默认资源包写入生成结果。

## 使用流程

1. 绘制闭合的水平地面道路，先拆分交叉路口，处理道路诊断并生成路面。
2. 点击「识别 / 刷新街区」，从下拉菜单选择街区，或开启「在画布点选街区」。曲线、凹街区可识别；桥面不作为围合边界，断头路仍参与避让。
3. 调整地块宽度、进深、路边退让、间隔、风格、种子和本批栋数。默认中世纪，也支持城中村和标准建筑。
4. 预览绿色可生成地块、蓝色已关联地块、红色被占用或保留的地块、灰色下一批地块，以及黄色入口接路线。换一个方案只改变空地块的房屋。
5. 点击「生成空地块房屋」。本批至多 16 栋，共用一次撤销；继续点击预览、生成可补充剩余空地块。

地块是保守的临街矩形，不强行填满整个多边形。转角、窄地、深街区中心、无法容纳屋檐或活动门窗的位置保持空白。地块和入口连接必须具有连续同高的实地覆盖，完整多边形扣除会检查角点之间的沟缝；不会自动填平河沟。入口连接另检查净空，不生成台阶、坡道或人行道，不等同于完整导航网格或玩家通行证明。

## 自动保留河岸、桥头和城门（2026-10-17）

预览和生成共用 `block_constraints.gd`：原生河道包含两岸，地形河流使用实际采样曲线与岸坡宽度；石桥按当前世界姿态预留两端各 10 米的通道，城门根据实际左右门轴预留双侧通道（墙体半厚度加 10 米）。保留区只排除相交地块和入口连接，不裁出异形房屋。隐藏或锁定源仍参与；城门打开后通道仍保留。旧平桥须保持配方对应的实际桥面几何，缺失或手改时拒绝猜测桥头；现代冻结桥和冻结城门沿用原生语义。

画布显示蓝色河岸轮廓和黄色通道，受影响地块显示原因；不再要求手工描河流禁建区。普通手动物件放置仍遵循既有几何与保护规则，不增加自动布局的全局禁令。已关联房屋不会因新增保留区自动删除。

## 道路变化后的已有街区更新（2026-10-17）

改变退让等设置后点击「预览已有街区更新」，确认橙色待移动住宅和蓝色原位保留住宅，再点击「应用已有街区更新」。也可开启「编辑道路时联动更新已有街区」后修改道路属性或拖动节点；道路骨架、已有铺面和受影响住宅在同一最终状态验证并一次提交。该开关默认关闭，UI 和 MCP 使用同一服务。

更新不重新生成房屋：保留建筑及构件 UUID、原房型／种子、原生材质、事件、门窗开合和手工整栋偏移。偏移随新临街坐标系一起变换；未受影响房屋的登记和构件记录保持原字节。冻结预制件原有的单面换材质限制继续生效。改变风格或种子只影响后续空位生成，不替换已有房屋。

应用前重新核对地图版本、外部资源身份、候选完整性及原生保存有效性。冲突、过期、保护或未知几何均无副作用拒绝；放弃候选不产生历史。应用后支持一次撤销重做、保存重开，派生显示与拾取继续接现有刷新和共享静态合批。

## 数据与修改保护

- 半边遍历提取道路平面图的有界面；先去掉图桥，避免断头巷和两个环路间的连接造成重复边界。嵌套独立环路在外层街区内作为孔洞避让。
- 街区 ID 根据定向边界构成，地块 ID 根据街区、临街边和槽位构成；调换道路数组顺序不会改变身份。道路新增、拆分造成拓扑变化时不保证原 ID 保持。
- `editor_layout.block_layout` 保存版本、上次生成设置和 `lot_id/block_id/building_id/source_token` 关联。新增可选 `anchor {position,yaw,entrance_local}` 作为更新基线，不保存临时预览网格或重复房屋构件。旧 v1 无 anchor 地图仍可打开：只有原道路／设置尚可对应且实际入口唯一时，更新候选才建立基线；原道路已改变则明确拒绝猜测。
- 已关联地块永不自动替换。手刷材质、事件、参数修改、整栋移动、锁定和隐藏都保留；房屋删除或解除其参数化身份后，该地块标为 `missing`，仍不会擅自补回。
- 边界几何、路宽、地块宽深、退让或间隔变化后，先使用已有街区更新。仅在旧街区／槽位无法对应或用户决定转为手工管理时，显式解除关联；解除仍保留房屋，隐藏、锁定或不在可编辑楼层的关联房屋会阻止解除。
- 未关联地块避让全部现有物件（包括隐藏或锁定的物件）、道路及其通行净空、禁建区、保留通道。房屋全包围范围包含屋顶、基础和门窗活动范围；另检查宽 2.1 米、高 3 米的入口接路空间。
- 原有房屋不因为后来新增保留区而自动移除；图形地块预览是规划辅助，普通手动物件放置没有新增全局限制。
- 保存、重开、自动草稿、撤销/重做都沿用文档恢复事务。删除的建筑 ID 可保留为地块墓碑，不会让地图保存失败。

## MCP

| 工具 | 语义 |
| --- | --- |
| `get_city_blocks` | 只读识别街区，返回 `blocks`、`bindings`、`settings`、`orphaned_blocks`、开放边及排除桥面数量 |
| `preview_block_buildings` | 只读；选填 `block_ids`（省略为全部）、`lot_width`、`lot_depth`、`setback`、`gap`、`style`、`seed`、`max_buildings`；返回地块状态、可生成房屋参数/位置/包围盒、入口连接和 `plan_token` |
| `generate_block_buildings` | 同预览参数，可传 `plan_token` 固定预览；再次校验后一次提交，返回稳定建筑 ID。无空位时成功但 `changed:false` |
| `preview_block_update` | 同地块设置、可选 `block_ids`，省略时选择全部已有绑定；可附 `road_changes {expected_token,nodes,edges,remove_nodes,remove_edges}`。返回 `plan_token`、更新／保留／缺失建筑 ID、最终地块、保留区及变更摘要 |
| `apply_block_update` / `discard_block_update` | 仅传 `plan_token`，分别原子应用／放弃；无变化候选不增加历史 |
| `update_road_graph` 的 `update_blocks:true` | 使用同一联合预览／应用服务；与 UI 道路联动开关一致。受影响的已关联街区一起更新 |
| `detach_block_buildings` | 必填 `block_ids`；解除选定街区关联，包括拓扑改变后已消失的旧街区，保留房屋；一次撤销 |

生成 `plan_token` 包含道路、保留区、全部原有记录／地图元数据（含地形河流）和选定设置；联合更新的令牌绑定私有完整候选及资源身份。预览后相关状态改变拒绝旧令牌，无文档或历史副作用。UI 与 MCP 复用 `block_tools.gd`／`block_update_tools.gd`，当前二维适配器保持停用。

状态值：`ready` 可生成，`retained` 已关联且原位保留，`updated` 待移动，`missing` 关联房屋已删除/脱离，`occupied` 现有物体占用，`reserved` 禁建或保留区，`river_reserved`／`bridge_access_reserved`／`gate_access_reserved` 为自动保留，`ground_unavailable` 缺少完整同高实地，`access_blocked` 入口无法接路，`too_small` 无合适房型，`pending` 本批达到栋数上限。`skipped_corners` 统计未形成有效矩形地块的槽位。

## 当前边界

- 道路骨架仍为 256 节点、512 边上限；最多识别 128 街区，单街区最多 512 地块，一次预览最多 1024 地块，每批最多生成 16 栋，持久关联与建筑各最多 4096。
- 平面道路、保守矩形地块；自动河流避让已完成，不支持斜坡地块、异形房屋或街区中心递归分割。复杂坡地仍使用住宅整地／接路联合候选。
- 仍使用整批规划及现有完整场景重建，尚未完成大型城市增量生成、局部撤销存储或性能交付。不能将这批视为参考城镇整图已经完成。
- 已有街区每次最多移动 16 栋、预览 1024 个地块。道路节点移动、路宽及退让变化须保持旧街区和槽位可一一对应；拆分／合并拓扑、消失地块、手改构件几何、超出新地块的房屋都拒绝整批更新。不会缩放、删房、最近邻猜配或重新生成以覆盖手改。已删除住宅保留墓碑，不补回。
