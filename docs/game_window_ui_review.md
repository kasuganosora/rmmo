## 游戏 UI 美术打磨（2026-10-02）

本轮只修改 `scripts/ui/` 的游戏皮肤和应用位置。内容编辑器未接入、未修改这套主题。沿用现有道具及技能图标；游戏窗体、控件和菜单符号使用代码原生几何，避免把位图边框放大造成模糊或厚边。

| Before | After | Why |
| --- | --- | --- |
| 偏绿底色、多层金属亮边 | 炭灰微渐变、单层细轮廓、轻微顶光 | 降低厚重感，保留材质层次 |
| 标题与正文分量相近 | 暖白标题、灰白正文、灰色辅助信息 | 建立稳定文字层级；标题继续不套内框 |
| 所有按钮几乎同样显眼 | 中性次要按钮，提交/制作/确认用低饱和暖金色 | 主要操作更容易识别 |
| 内层面板再套框 | 以细微底色差区分分区 | 降低框线密度 |
| 格子双层硬边，未解锁格子近乎纯黑 | 单层微圆角格子、细金选中边、低对比未解锁区域 | 道具优先，空格不抢眼 |
| 菜单图标来自不同像素样式 | 同一线宽的角色、背包、技能、任务、队伍、地图、设置图标 | 提高整套 UI 的一致性 |
| 滚动条亮边多、滑条配色不一致 | 中性细滚动条、暖金滑条、柔和状态条渐变 | 控件与窗体统一 |

高频交互无装饰动画，按钮各状态保持相同内边距，避免悬停时文字位移。当前以 Windows 中文字体、100% 与 130% 缩放验收。

## 共用组件

`scripts/ui/game_window.gd` 是游戏窗口组件，统一外框、无边框标题、关闭按钮、内容间距、标签页、表单行和背包物品选择器。标题区域使用 `StyleBoxEmpty`，不能另外绘制内层标题矩形。普通窗口只从标题区域拖动，避免与列表及物品拖动冲突。关闭走各窗口原有业务回调，Esc 按实际前后顺序关闭最上层窗口。

主窗口和辅助窗口记住拖动位置，改变缩放或视口尺寸后重新限制在屏幕内。缩放后的边缘调整按屏幕坐标转换，避免边框比指针移动更快。共用按钮使用轻背景和细边，标签页以下划线表示选择，列表使用细分隔线。高频操作即时响应，不增加装饰动画。

## emil-design-eng 逐窗复核

| Before | After | Why |
| --- | --- | --- |
| 共用标题另套一层凸起框 | 统一 GameWindow，无框标题和单一外框 | 消除重复边界，保持一致层级 |
| 背包搜索与物品一起滚动 | 筛选、搜索固定顶部，物品区域独立滚动 | 查找条件始终可操作 |
| 角色信息和属性分配堆在一起 | 概况/属性分页，刷新后保持所选页 | 分配属性时不跳回概况 |
| 查看玩家时纸娃娃区域拥挤 | 增大查看窗口可用高度，统一留白 | 展示完整装备槽 |
| 技能单击可能直接施放，缺少名称 | 单击查看，独立使用按钮，图标带名称 | 降低误施放，支持拖入快捷栏 |
| 任务标签和列表重复厚框 | 共用轻标签、细分隔列表及无框详情标题 | 保留任务状态和详情入口，降低视觉负担 |
| 地图说明占据空间，移动后难找角色 | 压缩说明，完整提示放 tooltip，3D 地图增加回到角色 | 提供明确的定位恢复入口 |
| 设置长列表和控件宽度混乱 | 用途分组、子页、对齐表单、固定底栏 | 查找与修改设置更直接 |
| 邮件收件和写信混排，附件要填 ID | 收件箱/写信分页；展开当前邮件；背包格子选择附件 | 草稿切页保留，减少无意义输入 |
| 拍卖购买和出售混排 | 购买/我的出售/上架物品三页，首列道具格子＋详细信息列表；上架独立选物区域，明确整组售价 | 区分买卖任务，防止单价/总价误解 |
| 仓库点击即移动，数量操作不明确 | 双格子区域与方向提示，先选物品及数量，再明确存入/取出 | 降低误操作并支持整组转移 |
| 制作配方和执行操作拥挤 | 配方产物格子/材料格子分栏，固定数量与制作按钮 | 材料不足和可制作数量立即可见 |
| 好友每行堆全部操作 | 选择联系人后显示其操作，离线限制相应操作 | 保留可发现性，减少按钮噪声 |
| 队伍成员增多后挤出操作入口 | 成员独立滚动，邀请、拾取规则和离队固定底部 | 满队时仍能操作 |
| 公会成员与会话操作混排 | 名单换行处理，离会/解散固定底部 | 长名单不挤占关键入口 |
| 称号锁定符号与说明重复 | 全部/已解锁筛选，明确条件、轻分隔 | 快速找到可以佩戴的称号 |
| 成就使用符号和重复框线 | 全部/已解锁筛选，状态与条件分层 | 提高进度扫读效率 |
| 日常任务状态和按钮重复 | 按钮直接表达接取状态，简化列表 | 一处呈现当前可做的动作 |
| NPC 选项是很小的居中文本链接 | 整行可点击选项，明确悬停和按下反馈 | 扩大有效点击范围 |
| 商店确认动作与当前页关系不清 | 购买所选/出售所选，空选择禁用，回购页隐藏该动作 | 按钮含义对应当前任务 |
| 交易报价列表长时撑高窗口 | 双方报价格子独立滚动，背包格子选数量放入/取回，明确双方锁定状态 | 保留锁定/确认区域，避免误判成交条件 |
| 战斗日志新记录强制滚到底部 | 只有本来位于底部时才跟随新记录 | 不打断阅读历史 |
| 动作和面部表情同时铺开 | 动作/面部分页，保留各自执行入口 | 减少一次呈现的无关选项 |
| 战利品关闭后果不明确 | 放弃剩余按钮、说明及空列表禁用全部拾取 | 明确动作后果 |
| 丢弃/拆分弹窗过大 | 紧凑数量表单、全部按钮、按动作命名标题及确认 | 用最少步骤完成数量操作 |
| 死亡对话说明与按钮分离 | 两个纵向按钮直接写复活地点和血量 | 选择前即可理解结果 |
| 组队邀请和分配弹窗被居中偏移撑高 | 共用按实际尺寸居中，分配按钮带用途提示 | 弹窗大小符合内容 |
| 菜单与其他窗口按钮质感不一致 | 使用共用按钮反馈，保留七个直接入口 | 避免额外操作层级 |
