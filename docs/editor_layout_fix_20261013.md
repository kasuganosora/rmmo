# 内容编辑器布局修复验收（2026-10-13）

对应 [apple-design 布局审查](editor_layout_apple_design_review_20261012.md) 的 A1–A8，以及用户补充的“城防表单是否需要占这么多地方”。采用紧凑表单、稳定任务上下文和明确反馈；没有加入模糊背景或高频动画。

## 空间占用

- 默认侧栏为 330 逻辑像素；1920×1080、项目画布缩放 1.5 倍时约 495 物理像素。允许手动调整，恢复偏好限制在 310–440 逻辑像素；拖动上限为 520 与可用宽度 45% 中较小者，并保留最小宽度。实际宽度也受控件最小尺寸影响。
- “视图 → 恢复侧栏标准宽度”可回到默认值；宽度与字号属于本机界面偏好，不写入地图和撤销历史。
- 删除重复的“工作面板”选择行和地形/城防标题。常用任务直接显示，其他任务进入“更多”。
- 城防短标签与控件同行，布尔项直接显示实际含义，说明压为一行并保留完整悬停提示。布局页常用参数无需滚动；预览/应用固定在底部。地形雕刻、表面、新建及河道的短字段同样紧凑排列，向量、点列表和材质选择保留需要的宽度。

## 审查项落实

|审查项|实现结果|
|---|---|
|A1 入口与分组|素材、属性、地形、建筑、城镇、城防为可见任务入口，其余进入“更多”；NPC、采集点、传送点集中到“添加…”。变换与相机工具分组。|
|A2 地形长表单|拆分雕刻、表面、河流、洞穴、岩岸、新建六页；雕刻仅显示当前工具需要的参数，表面编辑与新建分离。各页独立滚动，主要提交区固定。|
|A3 城防状态与长表单|独立城防任务，布局/结构/塔楼/材质/城门/管理六页。冻结结构明确只读，隐藏不可用的生成操作，保留门开度、地形跟随等有效管理能力。|
|A4 工具抢占面板|W/R/T 切换变换保留当前任务页；显式选择/摆放仍可进入相应面板。|
|A5 身份和错误|顶栏常驻地图名、未保存及加载/保存状态。接入统一反馈的操作错误独立保留，可看详情或关闭；工具提示、缩略图完成和无关操作成功不覆盖错误，同一操作成功后清除。|
|A6 标签与值|吸附标签和下拉框成组换行；属性 XYZ 位于输入框外，长数值不遮轴名。属性标题优先显示素材/用户名称，内部 ID 放可展开详情。|
|A7 已有河道编辑|提供已存河道目录、新建入口和场景选择关联；同一地形关联多个河道时要求明确选择，水面对象优先精确关联。校验/生成及结果区固定，目录浏览不修改地图。|
|A8 键盘操作|统一可见焦点边框；虚拟素材网格支持方向键、Home/End、PageUp/PageDown、Enter/Space，自动滚入视野，保留逻辑焦点，浏览不误放置。|

次级项：城镇概览可收起并保存偏好，窄画布缩小；散布显示已选数量、被筛选隐藏的数量及逐项移除；视图菜单支持 14/16/18 逻辑字号，现有与后建控件继承同一层级。

## 实现时一并修复的问题

- 城防采用最终父节点构建，避免面板重挂导致材质目录订阅断开。
- 城防、河道的无关目录刷新不覆盖未提交草稿；城防配方和门数组深复制，编辑草稿不提前修改文档。
- 城防默认参数覆盖顺序修正；载入旧冻结门高不强制改成新表单下限；椭圆请求排除折线路径专用参数。
- 城防点选路径使用当前所属任务页；Enter/Esc 保留正确上下文，离开绘制任务时取消。
- 概览 GUI 点击优先交由控件处理，绘制时点击收起按钮不增加路径点；已有拖动/笔刷/相机手势仍可收到释放事件。
- 同步打开地图成功时清除之前的打开失败提示。错误路由覆盖本轮相关操作和公共面板，并非重写所有历史状态栏写入点。

## MCP 与范围

复用当前 3D 的河道、材质、城防等业务操作、参数校验、撤销和保存路径；没有增加绕过业务的 UI 写入，也未重新启用旧二维工具。新增内容主要是导航、目录选择、反馈与本机界面偏好，业务工具 schema 不变。纯 UI 的侧栏宽度、概览折叠及字号无需地图 MCP 操作。
