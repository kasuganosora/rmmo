# 游戏快捷栏

游戏 HUD 专用；不改内容编辑器的界面或 MCP 能力。

## 操作

- 默认显示 1 排。悬浮图标排没有标题栏、外框或整体底板；右键页码或锁图标选择 1 / 2 / 3 排。每排 12 格，共 6 页。
- 第 1 排显示所选页，其余排依次显示后续页；第 6 页之后循环到第 1 页。每排左侧标明实际页号。
- 第一排：`1 2 3 4 5 6 7 8 9 0 - =`，也兼容 `F1–F12`。
- 第二排：`Ctrl` 加上述数字行按键；第三排：`Alt` 加上述按键。格子内的 `C+` / `A+` 分别代表 Ctrl / Alt。
- `Shift+1–6` 选择起始页，`Shift+PageUp / PageDown` 前后翻页。左侧小箭头也可翻页，右键菜单可直接选页。
- 聊天输入有焦点时不施放、不翻页；隐藏的排不响应快捷键。拖放期间不施放、不翻页。
- 点击格子使用。解锁时，拖到空槽移动、拖到已占用槽交换；按住 Ctrl 开始拖动则复制。
- 从背包或技能列表拖入是添加快捷方式，不消耗或移动实际物品。被动技能不可拖入。
- 拖到栏外或按 Esc 取消，原绑定保持不变。快捷栏物品拖动不能触发丢弃背包物品。
- 右键打开“使用 / 从快捷栏移除”菜单；移除后是真正的空槽，不再触发隐藏默认技能。
- 点击右侧小锁图标切换整理锁；锁定禁止拖入、换位和移除，点击与键盘使用正常。
- 拖动左侧页码移动整体；技能格只负责操作，排间空隙不阻挡游戏场景鼠标。
- 默认布局与聊天区保持 12px 间距；横向放不下时置于聊天区上方，窗口和 UI 缩放变化后重新避让。玩家手动放置的快捷栏保持自定义位置。

## 保存

页码和绑定按服务器、账号、角色 ID 保存在 `user://game_settings.cfg` 的 `hud.hotbar_profiles` 中；GameSession 保留场景切换副本。角色之间互不覆盖。首次使用将原来隐藏的 5 个默认操作显式放入首排，后续清空不会重新补回。旧会话已有绑定保留原来的页面和槽位。

排数、整理锁和栏位置保存在游戏设置中。匿名 HUD 或编辑器试玩仅保留会话状态，不写角色配置。快捷栏占用的按键在系统按键设置中提示冲突。

## 设计技能检查：emil-design-eng

| Before | After | Why |
| --- | --- | --- |
| 字体自带的上下小三角仅几个像素，难以发现 | 独立细线箭头、26×14 点击区、提亮当前页码；悬停与按下即时淡金反馈 | 明确翻页方向与可点击性，保持无底板样式 |
| 聊天区与快捷栏重叠，聊天“战斗”标签混入快捷栏截图 | 默认布局避让聊天区，窄屏上下排列；预览使用真实默认布局 | 区域边界清楚，避免把背景标签误认为快捷栏控件 |
| 只显示一排，页面与实际触发键不同步 | 1–3 排、6 页，数字键操作当前显示的排 | 看见的图标与按键行为一致 |
| 图标只能拖入，无法整理 | 原生拖放阈值、跨排交换/移动、Ctrl 复制 | 将使用与整理明确分开 |
| 右键立即清空，空槽仍触发默认动作 | 显式菜单移除、空槽无动作、可锁定 | 防止误操作，清空语义一致 |
| 常驻粗框、标题和大面积设置控件 | 无底板悬浮图标排、页码兼作把手、小锁图标；设置收进右键菜单 | 保留游戏画面，减少视觉噪声 |
| 厚重方形格、底部小字 | 40px 图标、1px 低对比圆角细边、左上角清晰按键提示 | 接近 FF14 的轻量快捷栏层次 |
| 翻页重建控件 | 翻页复用格子，即时更新；冷却及施法遮罩同步 | 高频操作无过渡延迟和布局跳动 |
| 放置反馈不明确 | 有效落点金色描边、来源变淡、原生拖动预览 | 提供即时反馈，不加装饰动画 |

参考 FF14 官方交互说明：[动作拖入](https://na.finalfantasyxiv.com/uiguide/know/know-hb/hotbar_registration.html)、[快捷栏与整理锁](https://na.finalfantasyxiv.com/game_manual/view/)、[快捷栏布局](https://eu.finalfantasyxiv.com/uiguide/know/know-hb/hotbar_shape.html)。本项目的页数和组合键是本地实现方案，不声称复制 FF14 默认键位。
