# 地表材质区域（2026-10-03）

地形面板的底材饱和度控制为 0（灰）～1（原色），只调底材颜色，保留原图与法线，区域覆盖与河床沙石颜色不变。“仅应用底材饱和度”保持原底材；`set_terrain_material` 可只传 `id` 与 `saturation`，省略则保留当前值；`list_terrains.saturation` 返回当前值。非默认饱和度与手刷三角面覆盖互斥，区域工具不受影响。

地形面板选择 PBR 材质后，可拖出矩形，或点选多边形角点、Enter 提交。Backspace 回退角点，Esc 取消；删除列表中的区域会从所有关联地形删除，露出下层覆盖。软边以米计，覆盖强度 0.01～1。一次绘制跨多块地形，整笔只有一个撤销项。区域撤销/重做只刷新有变化的地形；地图设置、物件顺序或其他几何变化仍走完整恢复。

当前 3D MCP 共用 `terrain_region_tools.gd`：

```json
{
  "name": "paint_terrain_region",
  "arguments": {
    "id": "market_courtyard",
    "terrain_ids": ["terrain_a", "terrain_b"],
    "polygon": [[10, 24], [50, 21], [56, 40], [14, 44]],
    "material_id": "pack:default:terrain/natural_dirt/material",
    "feather": 5,
    "opacity": 0.8
  }
}
```

输入多边形为世界 XZ 米，保存为每块地形的局部 XZ 米。相同 ID 在所列地形上替换原范围、材质和强度，保留覆盖顺序；新 ID 在上层绘制。请求应列出旧、新区域涉及的全部地形，范围移开时会清除原覆盖。区域 ID 是字母/数字/下划线标识。`remove_terrain_region(id, terrain_ids)` 删除指定区域；`list_terrains.ground_regions` 返回材质和完整区域记录。保存重开、预制件复制以及资源依赖检查都使用同一记录。普通复制和预制件实例会重新生成区域 ID，保留副本内部跨块关联，避免区域删除影响原件。

每块为一个底材加至多两种区域 PBR 材质，最多 32 个区域、256 个总顶点；每次指定至多 64 块地形。单个多边形最多 64 顶点，必须简单、不自交、面积至少 1 平方米。超出 800 万估算遮罩边测试工作量时，在修改文档前整批拒绝，提示减少地形或顶点。锁定、隐藏、楼层隔离、手刷三角面覆盖、透明材质、无效/缺失贴图也整笔拒绝。支持平移和 Y 旋转；绘制入口拒绝 X/Z 倾斜。软边最小 1 米，最大 24 米。

区域覆盖原始地表层，河床沙石与陡坡露岩规则优先。几何、碰撞、河面、道路和地形洞口不变。雕刻后覆盖仍贴合原高度场；不使用漂浮叠片。区域坐标与羽化宽度采用局部米制，直接改变地形尺寸时保持米制区域大小。细节分辨率为每块 257×257：200 米块约 0.78 米/像素，因此不适合刻画厘米级边线。

渲染保留完整法线、粗糙度、AO 和金属度。区域边缘使用连续权重与世界坐标噪声；同材质相邻块保留完整多边形，在边界采样同一点，不沿块边裁剪出新的软边。派生双通道 RG8 遮罩每块约 129 KiB，材质缓存复用，只有编辑时重建。合批工作线程只处理 CPU 几何与图像数组，GPU 上传在主线程提交，避免撤销、保存或退出时等待工作线程形成互等。合批使用 Texture2DArray 和原物件索引，不因每块遮罩不同而拆成独立绘制；未命中的材质不采样，无额外网格或碰撞。源遮罩与合批遮罩仍各占一份纹理内存，不能把它们计作零显存。

未启用的区域材质参数不参与合批变化判定，避免着色器首次使用时延迟填入默认值而触发无改动重建。`tools/test_ground_batching.gd` 验证首次合批后再次同步为零次构建，并检查渲染、碰撞与源网格保持一致。

验收脚本 `tools/test_world3d_terrain_regions.gd` 使用后台 GPU 桌面与临时地图，覆盖真实 HTTP 发现和调用、非法/保护调用无副作用、撤销重做、保存重开后继续绘制、UI 多边形与矩形输入、共享边缘遮罩、预制件贴图依赖、雕刻共存、原生运行时恢复，以及同视角合批/未合批渲染差异。结果位于 `D:/code/rmmo_runtime/review_artifacts/terrain_regions/`。

参考城镇配方在 `tools/medieval_town_layout.json.ground_regions`，图像坐标换算后调用这些正式操作；`tools/apply_medieval_town_regions.gd` 在河道修正候选上通过真实 HTTP 应用区域、保存重开并检查几何不变。区域是农田和空院的地表基底，垄沟、作物和地上物后续另做。
