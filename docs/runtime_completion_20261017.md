# 建筑远景、静态资源退役与目标 GPU 预加载

用户要求持续完成三项，无需每批重新确认。本批只在隔离 `codex/editor-reliability` 开发；不操作 `D:/code/rmmo` 的场景、工作分支或进程。正式地图与模型母版不改写。统一方案第 6 项在下述范围交付，其他 W/T 工作包继续按独立证据推进。

## 建筑远景与模型复验

自动服务每 250 ms 检查一次，240 米外准备、200 米内恢复；每栋按原渲染层和阴影模式分别生成代理，最多 32 个代理、每个 65,536 顶点和 128 米跨度、一个 CPU 准备线程。源楼层、屋顶、碰撞、作者 UUID 和保存记录保留，活动门窗独立。隐藏、移动、删除、替换或批次清理使受影响代理立即撤回；通知期间只隐藏并排队销毁代理，避免破坏引擎变换遍历。取消或离场后的旧工作结果不能重新发布。不能减少提交的结果退回原渲染，失败重试有冷却。

派生网格复用原材质，静态不透明 `StandardMaterial3D` 才参与；透明、风动／任意 shader、覆盖材质、骨骼变形及超预算输入保留原路径。复杂代理使用 `ImporterMesh.generate_lods` 生成索引 LOD，`lod_bias=2`；基础数组不变，私有处理仅统一未使用通道的空数组表示。简单组件不强制生成 LOD。引擎实际 GPU 索引及 float32 阈值另行读回验证；不改碰撞或原模型导出，不声称所有有损 LOD 对任意资产无损。

依据 `rmmo-model-review` 复验共享 Blueprint 生成的三层 `townhouse`，真实烘焙、native 保存重开后再拍摄。2209 个源构件烘焙为 81 个独立组件；实际 reference glTF 为 86,385 字节，71 份唯一 rmres 合计 830,073 字节。输入参数、实际地图／rmres SHA、各组件顶点／材质槽、相机与渲染器见[证据](../review_artifacts/runtime_completion_20261017/evidence.json)及 `proxy_gpu.json`。这些是存储量，不能当作解码内存或 VRAM；母版为可重建程序配方和保留的源 native，回退为关闭派生路径。这是既有建筑渲染管线复验，不是新房型制作或正式地图布局验收。

同一相机、灯光、曝光、1280×960、MSAA4、Forward+；远距离阴影上限 1000 米并加入地面接影。近、中、远与远处窄 FOV 细节分别做开关对照，未显示人物。最终 PNG 本地做精确比较，查看副本实际为 quality=90 有损 WebP，保留尺寸、SHA 与压缩记录。已人工查看屋顶、烟囱、窗框、腰线、门口和地面投影，所测机位未见可见的非预期结构或阴影损失。仅近／中景可要求相同源路径的像素一致；远景派生不标为全局严格无损。

## 完整静态资源退役

原普通模型退役保留，新增原生静态单元服务。只有可信依赖目录给出边界与完整归属的建筑组、原生盒体／高度场／道路、自包含冻结桥梁及城防组参与；整组包含其活动件身份。NPC、采集、事件、座位等玩法所有者，未知边界／不支持的行为继续固定，不能用“完整”推断任意对象都可卸载。

需求范围和导航邻域均带 64 米余量，默认 10 秒宽限。一次最多检查 16 组、退役一组；渲染／碰撞／导航、源与目标传送 pin、批次／代理／发布工作、未结束门窗动画必须共同允许。部分建筑、部分导入命名空间和仍被建筑依赖的地形明确拒绝。提交中没有 await；更新索引后解除节点、物理、导航、派生缓存与 CPU 数据的所有权，材质热缓存失去强引用后仍允许活动场景弱引用复用。完整归属索引当前在提交时重建，不宣称此步骤已完成大型地图的增量索引提速。

保留的是紧凑、完整的作者引用和开合数值，回访使用原 UUID 经 SHA／归属／预算验证后重新发布。高度场仅为所需地块私有读入接缝依赖，完整顶点、UV、切线、接缝法线与 RF 过渡图与全图上下文一致，不让邻块解码数据长期挂在结果中。实际 GPU／物理／导航测试反复穿行两个相距 2400 米的住宅地块，网格、材质、纹理 WeakRef 在最后使用者退出后归零，驻留回到 4 个 spec；门开合 0.7 与原 UUID 恢复，作者记录和磁盘 SHA 不变。

## 目标场景 GPU 预加载

沿用 24 米最近入口识别和已验证 CPU 预读，在共享源任务账本中申请 1 GiB 保守预算、两个工作槽（协调／解析及一个内部工作线程）。预读 CPU 包转交后释放其旧租约；GPU 结果未消费前继续计费，工作槽仅在真正结束后归还。需求任务可抢占投机工作，取消／过期／离场须等工作结束和私有结果释放再归还预算。该预算是保守调度口径，不是实测 RSS／VRAM。

原生目标选择、文件 SHA、资源根、模型与纹理头部预算在分配前和接管前核验；超额、未知编码／外部依赖或不匹配时回到原确认流程。后台 MapLoader 关闭额外工作池与全局场景／权威发布，使用操作私有模板；GPU 网格、材质、纹理通过 2 ms 分帧发布的私有 64×64 视口绘制。单个引擎上传／导入单位仍可能超过分帧预算，不宣称源帧尾延迟已受硬限制，也不保证私有视口覆盖最终全部 shader 变体。

真实目标在树外，只有共享 GPU 资源的临时视觉节点进入私有视口。确认传送按路径、精确目标和 SHA 复用场景与同一 GPU RID；移交资源的临时持有在目标真实绘制后解除，不成为地图终生 pin。完整物理、导航、胶囊落点、第一帧、权威、淡出淡入及输入门槛继续执行，提前入场开关不启用。资源没有命中或验证失败时继续原确认加载。

实际 textured GLB 的材质／纹理上传、源场景缓存身份、同 GPU RID 接管、地图／模型字节变化拒绝、抢占、离场和预算拒绝均有合同。UI 提示和当前 3D MCP 发现说明同步；真实 HTTP 创建事件、非法请求无副作用、撤销重做、原生保存重开与实际试玩跨图 GPU 命中均通过。没有新增二维工具或强制传送接口，也没有正式地图写入。

## 验证与发布

最终 **18 组回归、1088 项检查通过，0 失败**，接受日志、逐项数量和源码 LF SHA 见[证据索引](../review_artifacts/runtime_completion_20261017/evidence.json)。检查包括重复断言，不把总数视为独立场景数。GPU 测试串行运行于 `tools/run_godot_background.py` 的不激活私有桌面。全部生成资源和图片在外部 `rmmo_runtime`，仓库只保存代码、报告与非导入型证据；实验失败日志没有冒充最终通过日志。

按既有授权独立提交，并在发布前 fetch／合并远端 main，正常非强制推送功能分支与 main；最终提交及远端核对记录保存在外部同名验收目录的 `publication.json`。不切换或重置场景搭建会话。
