# 参数化建筑：外观与室内共用蓝图

2026-10-01。第一轮已接入当前 3D 内容编辑器和 MCP：平地矩形建筑、1～3 层、基本房间与公共走廊、真实门窗洞口、楼梯及楼板开洞、双坡/平屋顶，以及批量生成和安全重生成。

## 使用

点击画布工具栏「建筑」或左侧「建筑」页。选择民居、商住楼或旅馆，设置宽度、进深、层数、每层房间数、层高、屋顶与外观。建筑位置为底层地面的中心脚点，正门默认朝 -Z，朝向绕 Y 轴旋转。

面板顶部「预览」显示半透明建筑，不修改地图；「生成一批」写入当前参数和批量位置。数量最多 16 栋，列数和间距控制排列，每栋使用独立身份和递增种子。全部占地校验通过后才提交，一次撤销删除整批、重做恢复全部身份。改动参数后需重新预览。

通过建筑下拉列表选择已有建筑，再用「预览」或「更新建筑」。更新预览暂时隐藏原构件，清除后恢复原可见状态。「聚焦所选建筑」可定位整栋；「解除关联」保留普通构件和组合；「删除」只删除该建筑拥有的构件。以上修改均可撤销。

## 内外一致的生成规则

`scripts/world3d/building_blueprint.gd` 是唯一的布局来源，UI 和 MCP 都通过 `building_tools.gd` 使用它。

- 每层按同一层高计算地板、门窗、隔墙与天花板。房间沿公共走廊排列，用真实门洞相连；模板定义房间用途标签。民居默认每层 2 间，旅馆预设为 3 间；商住楼底层标记为店铺/储物间，上层为卧室。
- 每个门窗开口包含墙段、水平坐标、底高、宽高、楼层和所属房间；墙体分块时直接减去这份开口，内外边框也按相同尺寸生成。窗洞中有玻璃构件，门洞不生成封闭门扇。
- 窗户位于所属房间外墙，房间隔墙放在房间边界。构件保留真实厚度，门框装在洞口边缘，门洞净宽保持 1.4 米（房间）或 1.6 米（入口），净高 2.2 米。
- 楼梯使用独立竖向区域，净宽 1.4 米，踏步深 0.28 米，踏步高不超过 0.17 米。各层楼板按同一个楼梯投影分块留洞，连续楼梯采用薄踏板保证上下净空；顶层洞口设护栏，楼梯出口连接上层平台。
- 顶层封顶、山墙和坡屋面共享屋顶标高与升高；山墙使用真实三角柱网格。运行时碰撞来自同一组网格，不另造一份不匹配的碰撞外壳。
- 生成构件带显式楼层标高，编辑器隔离某层时能看见其地板和构件，隐藏上一层楼板及屋顶。关闭楼层隔离后显示完整建筑。

参数范围：宽 9～24 米、进深 12～30 米、1～3 层、层高 3～4 米、每层 1～4 间、坡屋顶升高 0.5～4 米。墙厚 0.2 米、楼板厚 0.22 米。尺寸限制为当前通行布局预留足够空间，不支持任意缩小后挤压门窗和楼梯。

## 保存、修改保护与实例身份

蓝图版本、完整参数、建筑位置/朝向、构件映射和几何基线保存在 `map_meta.building_instances`；实际构件仍是可编辑地图记录。构件带 `building.id/part/floor/floor_y/role`，山墙另有 `building_shape=gable`。保存重开、草稿、运行时加载均校验配置和归属，普通构件复制/预制件快照解除生成归属，保留网格。

生成发生在编辑器中，运行时读取保存好的确定构件。相同参数和种子产生相同几何；不同放置获得独立建筑和物件 ID。更新时按语义构件键保留仍存在的 ID，新增构件获得新 ID。

当前采用保守的整体更新保护：

- 任何构件被手工移动、旋转、缩放或删除时，更新返回具体冲突并保留原建筑。隐藏、锁定或被楼层隔离的成员也会阻止整栋更新/删除；先关闭隔离或解除保护。
- 已刷材质或挂载事件的构件，几何未改变时保留覆盖。参数修改将改变或删除这些构件时拒绝更新，避免错误套用旧面索引或丢失事件。
- 修改后的建筑不覆盖相邻建筑及其他已有物件。占地采用包含屋檐的保守世界 AABB；旋转建筑的空角也会计入，因此可能需要更大间距。
- 底层脚点以下的现有地面可作为支撑，不视为占地冲突；当前不会自动测量坡地或填补悬空地基。应先准备水平地面，再指定正确 Y。

更新、删除和解除关联使用建筑 ID，支持超过普通多选 256 个成员的建筑。单批最多 16 栋、每张地图最多 100000 个物件；仍需按实际内容量评估性能。

## 3D MCP

当前共 **63 个工具**。入口、loopback 和资源根约束见 [world_editor_mcp.md](world_editor_mcp.md)。新增七项：

| 工具 | 行为 |
| --- | --- |
| `list_building_templates` | 返回三种用途的默认参数、参数 schema 和批量上限 |
| `preview_buildings` | 返回占地、房间、门窗、楼梯、入口及构件数量，无副作用；可用 `replace_id` 预览已有建筑的增量更新 |
| `generate_buildings` | `parameters` + 必填 `placements`，校验全部建筑后一次提交 |
| `list_buildings` | 返回各建筑 ID、参数、位置、朝向、数量和修改/保护冲突 |
| `update_building` | 必填 `id`，可选增量 `parameters`、整体 `position`、`yaw` |
| `delete_building` | 按 `id` 删除归属构件，一次撤销 |
| `detach_building` | 按 `id` 解除生成关联，保留普通构件，一次撤销 |

`placements` 每项为 `{position:[x,y,z], yaw:0, seed_offset:0}`；位置必填，其他可省略。`yaw` 范围 ±180 度，种子非负且不超过 2147483647，偏移最多 100000，偏移后的种子仍需在范围内。

```json
{"name":"preview_buildings","arguments":{"parameters":{"template":"shop","width":12,"depth":14,"floors":2,"rooms_per_floor":2,"style":"timber","roof":"gable","seed":20},"placements":[{"position":[0,0,0]},{"position":[16,0,0],"seed_offset":1}]}}
{"name":"generate_buildings","arguments":{"parameters":{"template":"shop","floors":2,"seed":20},"placements":[{"position":[0,0,0]},{"position":[16,0,0],"seed_offset":1}]}}
{"name":"update_building","arguments":{"id":"使用生成结果中的真实建筑ID","parameters":{"floors":3}}}
```

以上是 `tools/call` 的 `params`。预览返回结构化布局，UI 额外显示半透明几何；房间、开口和楼梯坐标为建筑局部米制坐标，使用 `position/yaw` 变换到世界，`entrance/bounds` 已是世界坐标。更新预览要求单个 placement，并沿用已有参数后应用增量。未知字段、非法尺寸、重叠及保护冲突都在创建撤销事务之前拒绝。
