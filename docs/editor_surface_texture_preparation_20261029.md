# 编辑器普通物件纹理准备补齐（2026-10-29）

编辑器 `LoadJob` 原本只为地形和冻结房屋预制件准备纹理；普通方块、原生模型上的表面涂刷以及其他生成结构的材质，在重开地图时可能回到主线程读取。现在所有记录通过既有 `SurfaceMaterials.definitions` 收集实际材质定义，继续共用纹理键去重、准备队列、编辑器预算和发布时的 owner 检查。已有原生模型缓存不再跳过该记录的独立面材质。

首次扩展后的静态复核还发现缺原生模型分支会跳过纹理计划，导致后续记录已经预排的共用纹理与当前记录的修复任务重复。先复现再修复：缺模型仍返回原来的缺失结果，不回退 GLB，但同样参与本次纹理计划。取消仍交给树级 drainer，未完成的 CPU 像素继续占用预算直到实际释放。
