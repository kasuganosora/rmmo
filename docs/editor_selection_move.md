# 多图层框选移动

右侧图层列表的左侧勾选控制显示，右侧“移动”勾选决定参与拖动的图层。当前绘制层仍由点击图层名称决定，三者独立。默认移动 z1、z2、z3 和 meta 通行标记，地面 z0 保持原位；需要搬地面或其他扩展层时自行勾选。

选择工具栏“选区”（快捷键 6），拖出矩形并松手；选框此后固定。在选框内按住左键拖动，显示半透明内容预览，松手提交。Shift 拖动重新框选；Esc 取消正在拖动的预览，空闲时 Esc 或右键清除选区。切换地图、工具、模式会取消未提交预览。

移动选中图层的非空格，空洞不擦除目标内容。相互重叠的源/目标矩形使用快照移位，不会吞格。目标越界或目标同层已有其他非空内容时拒绝整个操作并在状态栏说明。一次移动对应一步 Ctrl+Z / Ctrl+Y，保持精确瓦片 ID（包括自动瓦片形状）；这不是自动重铺地形工具。区域过大时提示分批移动，超过 4096 格的选区只预览边框以限制临时图像内存。

完整参数化住宅会同步更新 building_instances 的位置、组件、通行记录和底图，撤销及保存重载后仍可在新位置重新生成。只框中住宅一部分、遗漏相关层或实例已有未同步手工修改时拒绝移动，避免生成器在旧位置重建。事件/NPC/传送不属于这里的瓦片图层操作。

MCP `move_selection` 使用相同事务：

```json
{"x":6,"y":6,"w":5,"h":8,"dx":6,"dy":0,"layers":["1","2","3","meta"]}
```

测试：`tools/test_selection_move.gd` 覆盖重叠、多层、原地面、通行、越界/占用拒绝、稀疏分块、实例元数据、撤销与保存重载；`tools/preview_selection_move.gd` 在内存测试地图中驱动真实画布输入、预览、提交、UI 撤销重做和 MCP，不保存用户地图。GPU 截图落在其指定工作产物目录，移植运行时先调整路径。
