## 修复

1. `deferred_asset_loader.gd`：一个通用`visual_render/all`票覆盖相机范围，替代四个类型限定远景票。现有空间索引、共享模型/实例去重、字节准入、worker数量、分帧发布、入口scope继续使用。无需读取GLB或新增资源校验。
2. `world_stream.gd`：所有物件使用同一视觉范围，查询/发布/回收一致。`COLLISION_RADIUS=2`和脚下安全范围保持独立。建筑完整成员/支撑关系、原生图、作者LOD/可见性参数不被拆毁。
3. `visual_stream_range.gd`：使用实际Camera3D投影的八个裁剪角点计算绕玩家的保守范围，加32m余量覆盖当前最长12m相机臂。旧建筑1km规则与实际相机far=4000并不一致；没有通过缩小相机远裁面通过验收。宽屏、偏移、正交投影均覆盖；投影未变不重建范围，转向不反复卸载。动态范围变更走源版本失效，保留未完成工作。
4. `stream_cell_query.gd`：初始范围按占用索引与查询格数中较小者遍历；移动只查进入/离开的差分条带。稀疏地图不遍历64009个空格；大跳转的候选枚举本身也分帧，而不只对最终实例化分帧。
5. `visual_chunk_priority.gd`：同圈按图排序，再到外圈；大物件从最近占据区块排序。8方向加5度滞回，视角微抖不重排。脚下/显式传送等负优先级、近邻0、预测2、远景10层级保留。近邻票对齐完整4圈，避免旧±128m把同一边缘区块切成两种优先级。最终rank共用于派发和就绪发布，不另建有头部阻塞的队列。

## 最后复查

真实GPU结构回归 `V/structure_gpu02.log` 23/23通过、exit0、0错误：完整城门双扇原子发布、远墙与桥梁的实际碰撞、门交互、不同owner隔离、任务预算归零，以及正式资源不被改写。`structure_gpu01` 保留22通过/1失败：旧统计把信任资源后跳过selected复核误标成full scan。预检实际已使用现有ownership proof，故只纠正`ownership_proof_used`计数来源，不恢复复核、不改变加载行为。
