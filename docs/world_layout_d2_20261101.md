# D2 世界布局与接缝诊断

2026-11-01，接续 [D1 世界地址](world_address_d1_20261101.md)和[设计修订 2](world_space_address_research_20261018.md)。在 `codex/world-address-d1` 隔离工作区继续开发，D1 基线为 `c32ec8f02b22e9aced9befd61baec7d5baa7682d`；本批开始时重新拉取 `origin/main`，仍为已包含的 `6a1bf861973ea08af04a5ba2042587423862676c`。没有改动场景搭建工作区、正式地图或既有加载/渲染性能流水线。

本批交付作者侧的世界配置闭环：不同尺寸地图放置、连续空间、部分边接缝、地址双向转换、可定位诊断、候选应用、独立历史和保存。接缝实际几何检查限定为受支持的原生高度场外边；不构造运行时通行证据，不启用连续跨图加载。

## 使用

先在“文件 → 世界地址与地图编号…”登记并保存需要引用的地图。再打开“文件 → 世界布局与接缝…”，选择所属包、输入世界标识并新建草稿。每个世界可有多个连续空间；在空间内添加地图放置，填写地图编号、原点 XYZ、本地 XZ 归属范围。尺寸由范围决定，不要求正方形、固定大小或 32 米整除，也不从可见物件 AABB 猜测地图边界。

地图放置只平移，保留原地图本地坐标。接缝选择两个相向的边及各自区间；X 边区间沿本地 Z，Z 边区间沿本地 X。一条长边可以分段接多张小图。点击“添加 / 更新”将表单写入窗口草稿，再“预览 → 应用 → 保存布局”；应用是一笔世界配置撤销，保存不代存地图或编号目录。

俯视图显示归属矩形、接缝及诊断位置。选择问题可查看两侧本地坐标和连续空间坐标；地址输入可转换到已应用布局，空间 XYZ 可以反查所属地图。未应用的草稿不改变这些只读查询使用的布局。这里展示范围参考，尚未把邻图三维场景加载进当前编辑器。

退出保护覆盖服务中未保存的布局，以及窗口内尚未添加/应用的表单内容。刷新列表不会悄悄替换编辑基线；关闭可明确保留会话草稿。对所选布局的保存、放弃、重新载入均有明确目标，不批量丢弃其他世界配置。

## 坐标与结构约束

作者文件为所属包的 `worlds/<world_key>/world.json`，包含 `schema_version / world_key / units / up_axis / spaces`。每个空间包含 `placements / seams`，字段沿用设计修订 2；放置可选 `pack_version`，不保存绝对安装路径。

- `origin_m + local_position_m = space_position_m`，计算使用 float64 标量数组，未提前转换为单精度向量。输入及结果各轴限定在 ±1e12 米；这不是运行物理范围的承诺。
- XZ 归属范围采用左闭右开；边界点确定地归属右/上侧地图，Y 保留原值，不贴地。范围外返回错误，不钳位。
- 同一空间不能重复放置同一包/地图编号，同层归属矩形不得有正面积重叠。同地图在不同空间可存在，需要上下文消除地址歧义。
- 只允许平移，未知字段、旋转/缩放、非法数值和重复身份拒绝。上限为 32 个空间、总计 128 个放置和 256 条接缝。
- 接缝水平端点结构比较显式采用 0.001 米容差，保留实际偏差并报告，不修改坐标。此容差不用于填补实际地形空隙。未声明连接的相邻边段与多图角点作为信息提示，不强制自动封边。

## 事务、来源与保存

预览只生成会话候选，不创建目录或布局作者文件，也不压入历史。候选绑定所属包元数据、地图编号目录的磁盘 SHA 与编辑修订、各地图入口字节 SHA、布局磁盘基线及编辑修订；应用前重新验证全部来源。过期候选无部分应用，必须重新预览。

布局只引用已保存且没有脏修改/磁盘冲突的编号目录。首版引用范围为所属包与现有共享资源包；同包使用所属包的安装版本，共享包存在多个版本时用 `pack_version` 明确选择，不能按发现顺序决定。地图文件原有路径及 `map_ref` 不变。

保存要求 `expected_edit_revision` 和 `expected_disk_sha`，使用原生锁、暂存校验与单文件原子发布；首次创建使用不可覆盖已有目标的发布原语。资源根/符号链接、Windows 路径大小写别名、包元数据变化、布局文件并发修改均有检查。世界配置不包含自身 SHA，不声称地图、目录和布局之间已有跨文件原子事务。

布局文件上限 8 MiB，历史和会话候选分别保留最多 32 条。状态及退出检查读取缓存脏标记；磁盘扫描、哈希和地形检查发生于显式操作。包移走后可显式放弃孤立草稿，不递归重建丢失的资源包。重新出现或重新创建同句柄时保留单调修订，旧候选不能误用。

## 接缝检查范围

“检查已应用接缝”读取已保存的原生引用地图，复用现有原生定义读取与依赖 SHA 验证，不加载模型、纹理、物理或场景实例。检查结束后再次核对布局、目录、包元数据和地图绑定；期间来源变化时废弃结果。报告附带 `layout_inputs / layout_sha / document / selection`，`report_id` 同时绑定来源版本与本次空间/接缝筛选范围，不能把同一对地图上不同边段的结果混用。

在受支持的无旋转、无垄沟原生高度场外边上，检查覆盖、洞口、重叠歧义、采样间距/相位以及全部边界折点和区间中点的高度。两侧地图原点 Y、地形本地高度和尺寸缩放一起参与计算；高度差不取平均。间距/相位采用独立的尺度相关容差，不把 1 毫米高度容差用于放行不同采样密度。实际空隙、内部裁切线、非支持地形和不唯一的重叠覆盖均不能得到匹配结论。

报告的 `heightfields_match` 仅代表上述检查。`can_transfer=false`、`continuous_ready=false` 始终保留；桥梁/其他网格支撑、胶囊净空、法线材质水体、运行物理和导航列为未验证项。没有高度场的桥面不自动补地，也不自动判为可通行。首次支持的读取预算为单地图入口 64 MiB、25,000 条记录、原生引用文件累计 64 MiB，单次检查最多 8,192 个样本；这些是输入预算，不是 RSS/显存测量。

## 当前 3D MCP

| 工具 | 关键输入与行为 |
| --- | --- |
| `list_worlds` | 可选 `pack_id / pack_root`；发现作者布局及会话草稿，不创建文件 |
| `get_world_layout` | `document_id`；布局、文档修订、来源绑定及诊断 |
| `preview_world_layout` | `mode / layout / expected_edit_revision`；新建另传 `pack_id / pack_root / world_key`，更新传 `document_id`；返回候选与 `base_edit_revision` |
| `apply_world_layout` | `candidate_id / expected_edit_revision`；采用预览返回的 `base_edit_revision`，单笔应用 |
| `save_world_layout` | `document_id / expected_edit_revision / expected_disk_sha`；独立原子保存 |
| `discard_world_layout` | `document_id / expected_edit_revision`；显式放弃或重新读取 |
| `undo_world_edit / redo_world_edit` | 沿用 D1 工具，按 `layout:` 或目录句柄路由到各自历史；地图 `undo/redo` 不变 |
| `validate_world_seams` | `document_id`，可选 `space_id / seam_id`；已保存高度场作者边界诊断 |
| `resolve_world_address` | 原地址工具增加可选 `document_id / space_id / placement_id`；有布局时返回连续空间坐标，无布局保留 D1 行为 |
| `get_current_world_address` | 同样支持布局上下文；当前物件作者原点或真实胶囊脚点 |
| `locate_world_position` | `document_id / space_id / space_position_m`；反查确定的地图归属与公开地址 |

指定布局时由布局绑定包版本，不能同时传 `pack_root`。`editor_state.world_layouts` 返回缓存状态并明确 `continuous_runtime_available=false`；所有能力只注册到当前 3D MCP。
