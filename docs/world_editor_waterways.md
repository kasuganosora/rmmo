## 使用流程

1. 选取普通水平地面，点击“使用当前选中的地面”。地面顶面必须与“地面标高”一致。允许绕 Y 轴旋转，单块长宽不超过 1000 米；本批只接受未刷面、未分组、无事件、非自动瓦片/其他生成物的 `ground/grass/dirt/stone/sand` 盒形地面。带保护标记需先恢复可编辑状态。
2. 点选河道中心线，Enter 完成，Backspace 撤回一点，Esc 取消。中心线为 XZ 折线，可用多点表达弯曲；两岸作有界斜接，拒绝急折、自交和岸线重叠。
3. 设置水宽、每侧岸宽、岸顶标高、水面落差和水深。河道与两岸须全部落在指定地面内，原地面会裁掉实际河槽范围，外部剩余部分保留真实形状和原 UUID。河床、静态水面、两岸挡土面及端部挡土墙分别生成。
4. 在足够长的直线段增加桥梁：段号从 0 起，`t=0.5` 为中点。桥梁垂直于这一段，两端延伸为桥头；桥总宽 3～12 米，两侧各占 0.3 米栏杆，通行净宽相应减少。过于靠近端点/转角、落水桥头和相互重叠会拒绝。
5. 分别选择河岸、河床和桥面/栏杆材质。材质来自现有资源库，支持 PBR 法线、粗糙度等依赖及米制 UV。MCP 省略材质 ID 时新建用原色、更新保留原设置。原地面若需要精细刷面，宜先完成开槽，再解除关联后手工处理。
6. 预览只显示方案，不改记录或撤销。应用统一提交地面改形、生成构件和配方。点击已有河道可调整参数、路径或桥梁；同一河道更新时不能更换原始地面列表。

桥面与河岸顶面同高（高于原地面 2.5 厘米）；桥下相交的河岸降到桥板底，避免两张共面顶面闪烁。桥头直接接指定平地，预览返回世界端点。生成河道后可显式调用 `connect_waterway_bridge` 或在道路面板“将所选河道桥梁接入路网”，随后从桥头向外绘制引道，包括直线高差坡道；详见 [道路桥梁联动](world_editor_road_connections.md)。河道生成本身不自动拆改旧道路，与已有道路冲突仍会拒绝。

桥已接入路网时，河道同参数重生成允许；修改设置、解除配方或删除河道前须先解除全部桥梁路网绑定，避免把现有道路留下悬空端点。修改后重新接入并更新引道。绑定的虚拟桥边不作为河道生成障碍，已有桥体仍由河道配方统一保护。

## 保存、碰撞与保护

- 配方位于 `editor_layout.waterways`，保存完整设置、原地面快照和成员 UUID/签名。`records.channel_mesh` 是水平凸补片实体，复用路面 slab 网格生成器，但不附带道路净空语义；`channel_clearance` 单独保留水面上方及桥面通行空间。编辑器选取、建筑占地、植被支撑和运行时碰撞都使用真实补片，不用整个地面包围盒填回河槽。
- 水面 `collision=none`，河床、河岸和桥面提供真实网格碰撞，栏杆阻挡角色。没有水流、浮力或溺水规则；落水后角色可落到河床，本批不实现上下岸路径。
- 检查全部现有物件，包括隐藏/锁定物件；参数化建筑按整栋体积与门窗活动范围检查。水面及其上方保留体积也会阻止后续建筑和植被生成，不能在宽河中生成悬空房屋。
- 更新既检查新河道，也检查旧河槽，避免移动/缩窄河道时恢复地面覆盖后来放入的独立物件。所有改动前完成校验；失败不变更文档、历史或外部文件。
- 地面及构件手动移动、分组、改名、刷面、清除材质、事件或删除后均拒绝重生成。隐藏/锁定/楼层隔离同样保护；清单的 `modified_or_missing` 列出手改/缺失成员。当前采用整条河道保守保护，不自动合并手工编辑。
- “解除关联，保留现场”只去掉配方，保留开槽后的地面、河道和手工修改；之后普通复制或预制件也不获得河道所有权。
- “删除河道并恢复原地面”要求所有生成成员未改，删除本河道成员后恢复源地面；如果河槽中新放了独立物件，会拒绝回填。两种操作都支持一次撤销。
- 保存、草稿、重开共同校验元数据、网格及材质依赖。源地面不覆盖用户地图文件，只有显式保存才写当前地图；测试只用外部运行目录中的临时地图。

限制：每图最多 32 条河道，每条 2～32 点、总长不超过 1000 米、32 块源地面、16 座桥及 2048 构件。水宽 3～60 米，岸宽 0.5～8 米，落差 0.5～5 米，水深 0.5～10 米。网格按 32 米空间块划分；地面余形最多 512 个补片。几何预算 20 万次、物件碰撞 100 万次，超限拒绝。不同河道不能共用同一源地面，本批没有河流汇合、湖面、地形坡度、自动地形挖掘、桥拱或桥墩系统；端部封闭，不能声称已有连续水文模拟。当前仍全量场景重建及快照撤销。
