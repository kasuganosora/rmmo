# 连续地形编辑

2026-10-02：补充原自动瓦片之外的连续地形笔刷，UI 和当前 3D MCP 共用 `terrain_tools.gd` 校验与事务。支持挖坑、贯穿地面的洞口；洞穴和隧道留待后续。

## 使用

编辑器左侧顶部“工作面板”选择 **地形**，进入 **新建 / 转换** 页：选择普通水平地面，点击“将选中地面转换为可雕刻地形”；也可以填写中心、宽度、长度，在空白区域新建。转换保留 UUID、名称、颜色和水平范围，原表面高度不变。河道、建筑/自动瓦片构件、事件、手刷表面的地面不能直接转换，避免破坏既有关系。

在 **雕刻地形** 页选择地形及工具，设置半径、强度、硬度，然后“启用当前地形笔刷”。左键拖动、松开提交；Esc 回滚当前整笔并退出。圆环显示半径，右键/中键/滚轮仍可控制视角。修改参数后重新启用。地形列表与画布物件独立，可用“使用当前选中的地形”关联。

| 工具 | 行为 |
| --- | --- |
| 隆起 `raise` | 增加作用点高度，软边渐弱 |
| 下沉/挖坑 `lower` | 降低地表，保留坑底 |
| 整平 `flatten` | 朝指定世界标高移动，强度控制每次最大改变量 |
| 平滑 `smooth` | 按邻域旧值同步混合减少尖峰；强度最大按 1 处理 |
| 挖穿洞口 `hole` | 删除命中格的顶面、底面与碰撞，在剩余地形边缘生成切面 |
| 补洞 `fill` | 恢复格子及其保存的顶点高度 |
| 风化 / 坡脚堆积 `erode` | 陡处向相邻低处搬移高度，削缓岸顶并形成坡脚；不增加网格或运行时模拟 |

挖洞按格子中心命中，格距决定洞口精度。高度笔刷按路径距离插值采样，强度为每次采样的米数，不随帧率自动累加。整平需要明确标高；抬高地形不自动保证坡度可通行，玩家仍遵守原有坡度和碰撞规则。

## 数据、保护与边界

- 每块地形一个记录、一个网格；顶面共享顶点，两个渲染面（地表、底床/切边），不按格子生成场景物件。
- 默认底床位于初始表面下 16 米，创建时可设 1～100 米；地表须高于底床 0.1 个局部单位，越界整笔拒绝。
- 每轴 2～64 格，最多 4096 格；目标格距 0.25～8 米，实际格距为边长/格数。新建边长 2～256 米，大范围需拆块。各块独立，暂不跨块雕刻、自动同步接缝或做 LOD。
- 可整体平移、旋转、缩放；雕刻支持 Y 轴旋转，拒绝 X/Z 倾斜。`size.x/z` 是宽长，`size.y` 是高度倍率，`position.y` 是初始表面标高。楼层隔离按该标高归属，不按地下底床归属。
- 锁定、隐藏、隔层物件也参与碰撞/承托保护。侵入物件、挖掉其承托、填洞侵入地下物件时整笔拒绝，不自动搬动房屋、树木、道路。无碰撞的河道水面允许地形穿越水位；普通物件、实体护岸及有碰撞的水面仍参与保护。判定按受影响格的凸占地和高度范围保守处理；靠近边界可能需缩小半径。
- UI 一次拖动只有一次撤销，后续采样失败回滚先前所有修改；MCP 一条路径同样原子提交。活动笔刷期间拒绝其他 MCP 写操作，草稿不会保存半笔状态。
- 整体材质复用现有 PBR 库，支持颜色、法线、粗糙度、金属度、AO 和纹理重复尺寸；雕刻保留材质。局部表面绘制仍可用，但存在手刷覆盖时拒绝雕刻，需先明确清除，避免几何变化导致错刷。
- 保存、重开、草稿、运行时三角碰撞和预制件保存高度与洞格；预制件打包整体材质贴图，缺失依赖和越界路径按既有资源根规则拒绝。

城墙和植被支持已整平到指定标高的实心格；斜格不能伪装水平承托，洞格不参与占地。道路连通诊断读取实际地形高度和洞格。河道生成仍只接受原先的普通平地来源，不能把雕刻网格当盒子开槽；可手工雕刻河床。这一版不自动令道路/城墙/建筑追随任意坡面，也不自动生成坑内水体。

## MCP

当前共 111 项 3D 工具；地形雕刻的 5 项基础操作如下，另有通用坡度和河岸材质操作。旧二维 MCP 保持下线。

| 工具 | 参数/输出 |
| --- | --- |
| `list_terrains` | ID、名称、尺寸、格距、洞格数、世界标高范围和保护状态 |
| `create_terrain` | `source_id` 转换，或 `center/width/depth` 新建；可选 `cell_size/bedrock_depth/name/material_id` |
| `preview_terrain_stroke` | 与提交相同参数；只读返回修改格数、采样数、世界标高范围、洞格数 |
| `sculpt_terrain` | 必填 `id/mode/points`；可选 `radius/strength/hardness/target_height`，整平须给 `target_height`；风化另支持 `iterations/talus_angle/erosion_seed` |
| `set_terrain_material` | `id/material_id`；空材质 ID 恢复原色，不移除局部刷面 |

`points` 是世界 XZ 二维数组，最多 128 个路径点，插值后最多 2048 次采样。半径 0.25～32 米、强度 0.01～20、硬度 0～1。预览不锁定方案，提交按当前文档重新检查全部保护。

```json
{"name":"create_terrain","arguments":{"source_id":"现有地面UUID","cell_size":1,"bedrock_depth":16}}
{"name":"sculpt_terrain","arguments":{"id":"地形UUID","mode":"raise","points":[[8,8],[12,8]],"radius":4,"strength":0.25}}
{"name":"sculpt_terrain","arguments":{"id":"地形UUID","mode":"flatten","points":[[0,0]],"radius":6,"strength":10,"hardness":1,"target_height":0}}
{"name":"sculpt_terrain","arguments":{"id":"地形UUID","mode":"hole","points":[[-4,4]],"radius":2}}
{"name":"sculpt_terrain","arguments":{"id":"地形UUID","mode":"fill","points":[[-4,4]],"radius":2}}
```

## 验收

地形可使用[坡度与河岸材质](world_editor_river_materials.md)：`set_terrain_slope_materials` 让隆起的草/土缓坡逐渐露出岩石，默认 40° 开始、65° 完全露岩，三向投影防止陡面拉伸；启用后雕刻自动跟随，无须水位。河床 `set_river_materials` 另按水深混合沙/岩，自然模式也包含坡度露岩，砌石水渠则保留铺砌材质并增加水线湿痕。UI 与 MCP 共用，支持 2K PBR 法线、原生保存及撤销。

`tools/test_terrain_surface.gd` 覆盖高度场规则、纯函数无副作用、洞口/补洞、底床约束、旋转/平移标高、材质面数量、JSON 几何一致性。

`tools/test_world3d_terrain_sculpt.gd` 使用真实 loopback HTTP 验证发现、5 项新工具、6 种笔刷、原子失败、保护/碰撞、撤销重做、UI 拖动/Esc/中途失败回滚、草稿及保存重开、损坏文件拒绝、PBR 法线、预制件依赖。运行时检测坡面/坑底高度、洞口无底板；2.1 米胶囊角色站立及掉入洞口。GPU 测试只通过 `tools/run_godot_background.py` 后台独立桌面，全部使用临时地图。


## 风化与性能（2026-10-03）

`erode` 使用有界热侵蚀近似：从同一轮旧高度读取八邻域，仅在高差超过稳定坡角时搬移高度，并将削下的量加到低处。固定种子调节局部搬移速度，避免每次重开都变形。参考 [Jacob Olsen 2004 的 Thermal Erosion](https://web.mit.edu/cesium/Public/terrain.pdf)，不是完整水力侵蚀模拟。

- `iterations` 默认 8，1～32；`talus_angle` 默认 35°，15～70°；`erosion_seed` 默认 0，0～2147483647。仅 erode 使用这三个参数。
- `strength` 限制每次路径采样、每个顶点向外搬出的总米数；多次路径采样可累积。接收的堆积量可能来自多个相邻顶点。算法守恒高度场体积，平地和低于稳定角的坡面不变化。
- 固定块边界和洞边顶点，保护现有接缝与洞口。不会跨块搬土，因此块边需要另外设计过渡；不自动侵蚀砌石墙，不产生倒悬。
- 只处理笔刷包围范围，邻接关系每个采样建立一次并供各轮复用。每笔“候选顶点 × 迭代次数”总量最多 250000，超限在修改前拒绝；避免极长路径卡住编辑器。大范围使用少量迭代分段操作。
- 结果保存为原高度数组，运行时没有侵蚀计算、额外物件或新增面数。现有地形法线、三角碰撞、自动坡度材质随高度重建。UI/MCP 共用承托检查及事务，Esc、撤销、重做、保存语义与其他笔刷相同。

```json
{"name":"preview_terrain_stroke","arguments":{"id":"地形UUID","mode":"erode","points":[[20,0]],"radius":6,"strength":0.75,"iterations":8,"talus_angle":35,"erosion_seed":17}}
{"name":"sculpt_terrain","arguments":{"id":"地形UUID","mode":"erode","points":[[20,0]],"radius":6,"strength":0.75,"iterations":8,"talus_angle":35,"erosion_seed":17}}
```

`tools/test_terrain_erosion.gd` 验证守恒、无新尖峰、确定性、洞边/块边/笔刷外不变、预算拒绝与不增加面数；`tools/test_world3d_terrain_erosion.gd` 在独立地图通过真实 HTTP 验证 UI 参数、只读预览、合法/非法调用、物件保护、撤销重做、交互取消、保存重开和运行时碰撞。截图、编辑耗时与日志在 `D:/code/rmmo_runtime/review_artifacts/river_bank_lab/weathering*`。

## 地面分块合并（2026-10-03）

编辑器与运行时自动合并附近的地形、道路和薄 ground 方块，不需要重存或转换地图。通常按 128 米空间格分组；较大地形使用覆盖自身尺寸的格，例如 200 米地形使用 512 米格。每组最多 16 个来源、65536 个输入顶点，保留分块剔除。完整材质参数、纹理资源、几何属性、阴影及渲染层兼容才合并，不能仅凭颜色贴图相同判断。

- `ground_batcher.gd` 保存派生绘制缓存；原 UUID、记录、选面索引和物理体保持独立。选中时恢复该块绘制，修改立即撤下旧合并组，仅受影响的组需要重新构建。隐藏、楼层隔离和渐隐物件不进入合并组，锁定仍由原操作校验。存盘重新从记录构建，不序列化合并网格。
- `ground_cpu_mesh.gd` 保存无 GPU RID 的原始数组和材质。合并完成后释放原 GPU 网格，也转换表面绘制的原网格引用；恢复时重建 GPU 资源。运行时未驻留的地面只保留 CPU 数据，碰撞和导航仍读取原三角形。普通内存仍需保存作者数据及碰撞，并非消除所有几何占用。
- 同材质的不同高度场使用 `Texture2DArray` 分层，每个顶点携带来源层号；保留各块的局部坐标、跨度、旋转及高度采样，支持自然河岸、深度和坡度混合。PBR 大贴图继续共享，仅增加小型 RF 高度层。
- 完全封闭、未逐面绘制地形的平底在派生网格中简化为四边形。顶面、洞口、切边、原选面与碰撞不简化；有贯穿洞的地形保留整个底面拓扑。
- 几何整理在后台线程进行，线程不访问场景节点；主线程完成替换。作业携带版本，编辑、撤销、重开或流式卸载后丢弃过期结果。CPU 数组按网格缓存，避免每次选中都重新回读 GPU；追加、变换、索引偏移使用独立数组，不能修改作者数组。
- 水、建筑、动态物件、蒙皮、自定义未适配着色器、透明材质、局部三向投影、反射或非均匀变换保留单独绘制。本轮没有处理房屋组件合并。降雨覆盖层跳过 CPU 来源，符合原覆盖条件的合并地面仍能接收湿润效果。

当前 3D MCP 的只读 `editor_state.ground_batching` 返回 `enabled/pending_groups/groups/source_objects/source_surfaces/render_surfaces/source_vertices/render_vertices/rebuild_count/last_build_ms/max_build_ms/last_commit_ms`。build 时间是包含排队及提交的墙钟时间，commit 是主线程替换时间；surfaces 是合并组的材质面数量，不等于整帧真实 draw calls。工具数仍为 111，二维工具保持下线。UI 与 MCP 原编辑入口自动使用同一缓存及撤销事务。

RX 7900 XTX、Forward+、独立后台测试视口，45 帧预热、80 帧采样；下面仅为地面视口，不代表完整游戏帧率或所有设备：

| 场景 | 绘制调用前 → 后 | GPU 缓冲监测前 → 后 | GPU 绘制中位数前 → 后 |
| --- | --- | --- | --- |
| 49 块不同高度河岸，含旋转与洞口，1280×720 | 98 → 6 | 22.26 → 18.73 MiB | 0.318 → 0.296 ms |
| 用户 1.4 公里城镇的 1007 条记录，1920×1080 | 2972 → 720 | 62.53 → 48.64 MiB | 0.581 → 0.416 ms |

城镇合并 831 个来源为 106 组，2453 个来源材质面变为 201 个合并材质面；像素平均通道误差约 `7.8e-8`。贴图显存基本不变（城镇高度层新增约 0.20 MiB），不能把缓冲下降 22% 宣称为总显存下降 22%。整图首次后台构建约 5.46 秒，构建期间帧时间 P95 为 23.9 ms，仍出现 87.2 ms 峰值；普通 49 块样例构建期 P95 为 2.29 ms、最大 10.76 ms。首次整图构建仍有优化空间，稳定视图不重复构建。
