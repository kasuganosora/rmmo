# 3D 表面材质笔刷

2026-10-01。第一批的“多选、分组、预制物件”和“表面材质笔刷”均已实现；楼层隔离显示、临时副本试玩及指定出生点也已交付，见 [world_editor_playtest_floors.md](world_editor_playtest_floors.md)。

## 操作

入口是工具栏 **刷材质…**、**编辑 → 表面材质笔刷…**，或左侧 **材质** 页。

1. 从材质库选择材质，或用 **导入贴图…** 导入外部内容根内的 PNG、JPEG、WebP。贴图复制进独立材质库，原文件保持不变。内置白色与棋盘格供基础绘制、检查比例使用。
2. 选择 **平面投影** 或 **模型原始 UV**，设置横向/纵向重复、旋转角度和偏移。默认平面投影将一张贴图铺满这个面的包围矩形；重复值 `2` 表示图案缩小、重复两次，`0.5` 表示放大一倍。
3. 点击 **选面** 后在画布点选，再点击 **应用到所选面**；也可点击 **刷材质** 后连续点选或按住左键拖过多个面。悬停高亮提示目标区域。一笔拖动对应一步撤销；Esc 取消当前未结束的笔画并退出。
4. **恢复原材质** 可连续点选或拖过需要恢复的面；**恢复此物件全部原材质** 清除所选面的所属物件上的全部覆盖。恢复操作也支持撤销。

画笔针对同一网格、同一原材质槽内的**相连共平面三角面**。方块六面可以分别绘制，墙、地面、斜屋顶和静态导入模型均可使用。不同物件实例、其他网格节点和未绘制的面保持原材质。模型原始材质仍由原资源提供，恢复时重建原网格；不会修改共享模型文件。

刷面允许单独处理组合成员，不改变分组和相对变换。锁定、隐藏、只读文档不能刷面。自动瓦片首次刷面会冻结当前造型、脱离邻接，并共同更新邻居；撤销恢复原自动关系。退出画笔或完成笔画后仍可使用 XYZ 自由变换。

## 保存、复用和边界

物件记录中的 `surface_paint` 保存模型节点路径、原材质槽、平面标识、几何签名、材质快照和 UV 参数。`surface_materials.gd` 为本实例构建网格并写入 UV，原模型及其他实例保持不变；glTF 导出自带绘制后的材质、贴图与 UV，运行时无需编辑器笔刷代码。

- 正式保存、重开、撤销/重做和恢复草稿保留全部刷面记录。缺失贴图会阻止正式保存；恢复草稿仍可查看缺失清单，并通过重新刷面或恢复原材质修复。
- 预制件同时打包贴图与模型，以相对路径引用。模型再次导入时可能重排顶点/三角面，打包会按实际三角面几何重新匹配刷面目标；匹配不唯一时拒绝保存该预制件。整个预制件素材库搬迁后仍能使用。
- 材质库位于外部内容根的 `cache/world3d/surface_materials/`；导入贴图最大 16 MiB、4096 × 4096。单次修改已有材质库文件不会自动同步已刷的材质快照。
- UV 重复范围每轴 0.01–100、旋转 −3600°–3600°、偏移每轴 −100–100。平面投影按模型局部面的包围矩形归一化；缩放物件会随之拉伸图案，并非固定每米密度。
- 本轮支持静态三角网格。蒙皮、BlendShape、自定义顶点通道暂不支持；每个原材质槽最多 50000 个三角面，单网格最多 128 个原槽，单物件最多 128 个已刷区域，生成结果不超过 256 个材质槽。曲面会分成多个平面区域，目前没有喷枪混合、像素级纹理涂抹或跨曲面展开。
- 无原始 UV 的模型需使用平面投影。替换模型后若网格拓扑改变，旧目标不会悄悄转移到其他面；可先恢复整物件原材质，再重新刷面。刷面会生成新的漫反射材质；原模型的复杂着色器、法线贴图等继续保留在未刷的区域，恢复原材质后重新生效。

图形操作中，按住鼠标的一笔会暂缓自动草稿；停笔后即使仍在刷面模式，自动草稿也能继续。MCP 写操作在 UI 刷面模式期间返回忙碌，防止与用户操作混在一起；退出画笔后即可调用。

## MCP

新增六个工具，当前 3D 服务合计 **40 个工具**。旧二维 MCP 继续停用，历史代码保留。

| 工具 | 用法 |
| --- | --- |
| `list_surface_materials` | `query`、`offset`、`limit`，返回材质定义及稳定 `material_id` |
| `import_surface_material` | 必填 `path`，可选 `name`；路径必须在外部内容根内，返回已复制材质的 ID |
| `list_object_surfaces` | 必填物件 `id`；分页返回 `target`、世界 `center/normal`、三角面数量、当前覆盖和不支持的网格提示 |
| `pick_surface` | 必填 `screen: [x,y]`，坐标相对于 3D 画布左上角；只读，返回物件 `id` 和 `target` |
| `paint_surface` | 必填 `id`、`target`、`material_id`；可选 `mapping: planar/uv`、`scale: [u,v]`、`rotation`、`offset: [u,v]` |
| `clear_surface_material` | 必填 `id`；传 `target` 恢复单面，省略恢复此物件全部原材质 |

`target` 是面列表或拾取返回的 `{mesh, surface, face, geometry}`，不要自行猜测编号。刷面和恢复返回实际 `changed_ids`，无变化不增加撤销历史。`editor_state.surface_brush_active` 表示当前 UI 画笔模式。UI 与 MCP 共用拾取、校验、变换参数及撤销事务。

## 验收

`tools/test_world3d_surface_paint.gd` 通过真实 HTTP 验证六个工具，覆盖点选六面、中文贴图导入、旋转/重复/偏移的 UV 数值、非法参数及锁定保护、原材质保留、实例隔离、自动瓦片冻结与撤销、带材质物件缩放、模型预制件重映射/贴图打包/搬迁、草稿、保存重开及运行时纹理。编码后的越界 glTF 贴图路径仍被拒绝。

GPU 模式驱动实际鼠标连续刷面、选面拖动、Esc、撤销和面板按钮，检查 1024 像素布局。使用 `tools/run_godot_background.py` 的独立后台桌面，不激活前台窗口。截图和日志位于外部内容根 `review_artifacts/editor_surface_paint/`。原 MCP、组合、变换、预制件、草稿恢复和原子保存作为回归。

网格数组与三角形拾取的实现依据 Godot 官方 [ArrayMesh 文档](https://docs.godotengine.org/en/stable/tutorials/3d/procedural_geometry/arraymesh.html) 和 [Geometry3D 文档](https://docs.godotengine.org/en/stable/classes/class_geometry3d.html)。
