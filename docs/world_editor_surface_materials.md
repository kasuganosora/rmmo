# 3D 表面材质笔刷

2026-10-01。第一批的“多选、分组、预制物件”和“表面材质笔刷”均已实现；楼层隔离显示、临时副本试玩及指定出生点也已交付，见 [world_editor_playtest_floors.md](world_editor_playtest_floors.md)。

## 操作

入口是工具栏 **刷材质…**、**编辑 → 表面材质笔刷…**，或左侧 **材质** 页。

1. 单击缩略图选择材质，可按名称搜索或按墙面、木材、铺装、地表等分类筛选。搜索和切分类不会更换当前画笔材质；当前选择始终显示在列表下方，**重置筛选**可回到全部材质。默认资源包的 PBR 材质与个人导入材质同时列出，详见 [default_material_pack.md](default_material_pack.md)。也可用 **导入新贴图…** 导入外部内容根内的 PNG、JPEG、WebP；该入口只导入颜色贴图。贴图复制进独立材质库，原文件保持不变。内置白色与棋盘格供基础绘制、检查比例使用。
2. 选择 **平面投影**、**模型原始 UV** 或 **按米重复（材质建议尺寸）**，点击当前材质下方的 **自定义…**，在右侧抽屉中设置横向/纵向重复、旋转角度和偏移。默认平面投影将一张贴图铺满这个面的包围矩形；重复值 `2` 表示图案缩小、重复两次，`0.5` 表示放大一倍。按米重复使用材质的 `tile_size`，例如 2 × 2 米贴图在 6 × 3 米墙面上重复 3 × 1.5 次。
   抽屉可通过 **← 收起**、再次点击自定义按钮或 Esc 收回，参数保留；**恢复默认参数** 将映射恢复平面投影、横纵重复恢复 1、旋转及偏移恢复 0，不改动已有刷面记录。切换其他编辑页会自动收起抽屉。
3. 点击 **选面** 后在画布点选，再点击 **应用到所选面**；也可点击 **开始刷面** 后连续点选或按住左键拖过多个面。按钮高亮表示当前模式，再点一次可退出；刷面时按钮变为 **结束刷面**。悬停高亮提示目标区域。一笔拖动对应一步撤销；Esc 取消当前未结束的笔画并退出。
4. **擦除材质** 可连续点选或拖过需要恢复的面；抽屉底部的 **恢复所选物件全部原材质** 清除所选面的所属物件上的全部覆盖。恢复操作也支持撤销。

画笔针对同一网格、同一原材质槽内的**相连共平面三角面**。方块六面可以分别绘制，墙、地面、斜屋顶和静态导入模型均可使用。不同物件实例、其他网格节点和未绘制的面保持原材质。模型原始材质仍由原资源提供，恢复时重建原网格；不会修改共享模型文件。

刷面允许单独处理组合成员，不改变分组和相对变换。锁定、隐藏、只读文档不能刷面。自动瓦片首次刷面会冻结当前造型、脱离邻接，并共同更新邻居；撤销恢复原自动关系。退出画笔或完成笔画后仍可使用 XYZ 自由变换。

## 保存、复用和边界

物件记录中的 `surface_paint` 保存模型节点路径、原材质槽、平面标识、几何签名、材质快照和 UV 参数。`surface_materials.gd` 为本实例构建网格并写入 UV，原模型及其他实例保持不变；glTF 导出自带绘制后的材质、贴图与 UV，运行时无需编辑器笔刷代码。

- 正式保存、重开、撤销/重做和恢复草稿保留全部刷面记录。缺失贴图会阻止正式保存；恢复草稿仍可查看缺失清单，并通过重新刷面或恢复原材质修复。
- 预制件同时打包颜色、法线、粗糙度、金属度、AO 贴图与模型，以相对路径引用。模型再次导入时可能重排顶点/三角面，打包会按实际三角面几何重新匹配刷面目标；匹配不唯一时拒绝保存该预制件。整个预制件素材库搬迁后仍能使用。
- 个人导入材质库位于外部内容根的 `cache/world3d/surface_materials/`；共享默认包材质从 `assets/materials/` 递归读取分类描述。导入贴图最大 16 MiB、4096 × 4096。单次修改已有材质库文件不会自动同步已刷的材质快照。
- UV 重复范围每轴 0.01–100、旋转 −3600°–3600°、偏移每轴 −100–100。平面投影按模型局部面的包围矩形归一化；按米重复使用网格局部米单位，适合生成建筑的实际尺寸网格。额外缩放模型实例仍会改变世界纹理密度，不是世界坐标投影。
- 本轮支持静态三角网格。蒙皮、BlendShape、自定义顶点通道暂不支持；每个原材质槽最多 50000 个三角面，单网格最多 128 个原槽，单物件最多 128 个已刷区域，生成结果不超过 256 个材质槽。曲面会分成多个平面区域，目前没有喷枪混合、像素级纹理涂抹或跨曲面展开。
- 无原始 UV 的模型需使用平面投影或按米重复。替换模型后若网格拓扑改变，旧目标不会悄悄转移到其他面；可先恢复整物件原材质，再重新刷面。刷面会生成标准 PBR 材质，按新 UV 重新生成法线切线，并按材质 `normal_format` 将 DirectX 法线转换为 OpenGL。原模型的复杂着色器等继续保留在未刷的区域，恢复原材质后重新生效。高度/置换贴图保留在原始下载包，本轮没有接入几何置换。

图形操作中，按住鼠标的一笔会暂缓自动草稿；停笔后即使仍在刷面模式，自动草稿也能继续。MCP 写操作在 UI 刷面模式期间返回忙碌，防止与用户操作混在一起；退出画笔后即可调用。

## MCP

表面材质对应六个工具，当前 3D 服务合计 **67 个工具**。旧二维 MCP 继续停用，历史代码保留。

| 工具 | 用法 |
| --- | --- |
| `list_surface_materials` | `query` 搜索名称/分类/ID，`category` 精确筛选，支持 `offset`、`limit`；返回材质定义、来源、稳定 `material_id` 和全部 `categories` |
| `import_surface_material` | 必填 `path`，可选 `name`；路径必须在外部内容根内，返回已复制材质的 ID |
| `list_object_surfaces` | 必填物件 `id`；分页返回 `target`、世界 `center/normal`、三角面数量、当前覆盖和不支持的网格提示 |
| `pick_surface` | 必填 `screen: [x,y]`，坐标相对于 3D 画布左上角；只读，返回物件 `id` 和 `target` |
| `paint_surface` | 必填 `id`、`target`、`material_id`；可选 `mapping: planar/uv/meters`、`scale: [u,v]`、`rotation`、`offset: [u,v]`；复用材质定义的全部 PBR 通道 |
| `clear_surface_material` | 必填 `id`；传 `target` 恢复单面，省略恢复此物件全部原材质 |

`target` 是面列表或拾取返回的 `{mesh, surface, face, geometry}`，不要自行猜测编号。刷面和恢复返回实际 `changed_ids`，无变化不增加撤销历史。`editor_state.surface_brush_active` 表示当前 UI 画笔模式。UI 与 MCP 共用拾取、校验、变换参数及撤销事务。

## 材质浏览性能（2026-10-03）

材质目录扫描、资源根校验、文件版本检查在独立线程执行。缩略图原图读取、解码、缩放和 PNG 缓存读写由单个后台线程处理，主线程只接收完成的小图并上传显示，不等待正在运行的任务。首次显示缺少缓存的材质时生成缩略图；导入后当前材质也经过同一流程。

缩略图保存在外部内容根 `cache/world3d/surface_material_thumbnails/`，按材质定义、源文件修改时间和缩略图版本生成键。源图变化后的目录刷新会使用新缓存键。界面仅请求可见范围及当前材质，切换筛选会替换过期队列，隐藏页不继续排队。内存缓存最多 96 张小图，移出可见范围的列表项释放纹理引用。后台任务只处理数据与 Image，不访问场景节点；纹理上传仍按 Godot 要求留在主线程。

`tools/benchmark_material_picker.gd` 使用临时缓存验证生成、重开复用、筛选复用、按需加载、隐藏停调度及 110 种材质下的缓存上限。47 种真实材质实测：优化前单图同步解码最慢约 113 ms，目录刷新约 536 ms；优化后刷新请求的主线程提交约 0.1 ms（不代表目录扫描总耗时），小图上传最慢约 0.23 ms，初次只加载 8 张。性能数据与截图在 `review_artifacts/material_picker/`；时间取决于机器和资源。
