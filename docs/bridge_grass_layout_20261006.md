保留道路、建筑和特殊保留区。旧 `river_corridor` 是原河道通航投影，其中一部分覆盖后续已授权的干燥岩岸顶；本次只允许这些已验原生岸顶上的无碰撞装饰草，不在水面或通行空间种植，也不修改河道保护区数据。其他保留通道和禁植区继续避让。桥头零星草以实际地形与原生岸顶的较高表面落地。

使用当前原生 `prefab_library.place`，保持独立选择、位置、风动、三档 LOD 和资源依赖；整批内容有撤销/重做检查。修复了草导入时 COLOR_0 已存在但材质未启用的问题：只给带匹配顶点色的草表面使用共享派生材质，不改变无颜色表面或共享非草材质。`test_grass_vertex_colors.gd` 五项逻辑检查通过，素材真实 HTTP 保存重开也验证该设置持久。
