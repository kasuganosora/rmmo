# 原生草顶岩岸 / 岩壁

地形面板的“岩岸 / 岩壁”页签可新建草稿、从地图拾取岸顶点、修改 XYZ 和内侧接地标高、逐点调整宽度，预览后提交。已有岩岸可从列表或当前选择载入。数据作为 `rock_bank` / `rock_bank_materials` 保存在原生记录中，支持整段选择、移动、撤销重做和保存重开，不依赖一次性 GLB。

3D MCP：`list_rock_banks`、`preview_rock_bank`、`set_rock_bank`、`remove_rock_bank`。UI 和 MCP 共享 `rock_bank_tools.gd` 的规划、保护校验和事务提交。预览不修改文档；新建和更新各一次撤销。旧二维 MCP 不注册这些能力。

`points` 是世界 XYZ 岸顶折线；`height` 为向下岩壁落差；`cap_width` 为统一草顶宽度；可选 `inner_widths`、`inner_heights` 与点数一致，分别覆盖逐点宽度和内侧标高。`side` 为沿路径的陆侧。`direction_mode=normal` 使用岸线法向，`fixed` 按 `cap_angle` 指定世界 XZ 方向（0 度 +X，90 度 +Z），适合桥台附近定向接地。固定方向必须朝向指定陆侧。

`roughness`、`seed` 控制可复现岩面起伏；`water_level` 控制岩面湿痕。岩壁与草顶分别使用资源库中的不透明 PBR 材质，贴图参与依赖收集和资源根检查。岩岸带封闭端面、内侧及底面与真实三角碰撞。

操作会拒绝无效路径、自交、过急拐角、过陡岸顶、非法/缺失材质、隐藏/锁定/隔层目标、与实际物件或道路相交，以及覆盖受保护地形。手动岩岸不把自动街区布局限制升级为全局禁令；具体地图仍需按用户保留地要求验收。

这是原生局部岩岸网格，允许覆盖未保护地形，**不会自动挖除原高度场**。岸顶与内侧标高需与底层地形核对；不支持悬洞或任意拓扑雕刻。已手刷表面的岩岸需先清除覆盖再改参数，以免旧面编号错误转移。倾斜或 X/Z 非等比缩放后暂不允许参数重生成，仍可整体变换。

验证入口：`tools/test_rock_banks_mcp.gd` 使用临时地图和真实 loopback HTTP；`tools/review_bridge_terrain.gd` 通过后台独立桌面验证地形画面与碰撞，不抢焦点。当前验收记录须以实际日志为准，代码和流程说明不代表视觉已经合格。

## 自动性能处理

岩岸显式接入共享静态网格批次，不再依赖普通地面的高度阈值；编辑器和游戏按空间、材质及可见性自动合并。选择或修改时恢复独立源网格，完成编辑后重新合并。原生碰撞、UUID 和保存记录保持独立，未变化场景不重复构建。透明、动态和不兼容材质仍沿用共享批次的安全排除规则。

首次原生异步加载时，岩岸几何数组与道路、地形一起由后台线程准备；主线程只负责资源装配。岩岸生成器代码参与运行时缓存签名，更新后旧派生网格自动失效。无需用户手动执行合并或清缓存。
