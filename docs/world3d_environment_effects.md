# 连续昼夜、本地湿润、室内外声音与空间雷电

2026-10-02。运行时与 3D 编辑器共享 `weather_controller.gd`。新增配置通过现有 `get_environment` / `set_environment` MCP 暴露；UI 和 HTTP 使用同一 schema、校验、撤销事务和地图保存流程。没有启用旧二维 MCP。

用户明确要求：**实时湿润度、积水属于客户端本地视觉效果，不保存到服务器，不要求不同玩家一致**。服务器仍同步天气、时间、星空、流星及雷电事件。下列湿润初值和响应参数是地图作者配置，不是运行时湿润快照。

## 配置

| 字段 | 默认 / 范围 | 行为 |
| --- | --- | --- |
| `celestial_cycle` | false | 开启后世界时钟连续驱动日月、阴影、天空、环境光；默认保留旧地图手工主光 |
| `time_hours` / `time_speed` | 沿用 | 小时 0～24、倍率 0～3600 游戏秒/秒；0 暂停 |
| `surface_wetness` | true | 本地湿润与积水材质效果 |
| `initial_wetness` | 0 / 0～1 | 进入地图或重建预览时的本地初值，可预览雨后场景 |
| `wetting_seconds` | 90 / 10～3600 | 湿润指数响应时间常数，一倍时间约接近目标的 63% |
| `drying_seconds` | 300 / 30～7200 | 干燥响应时间常数，停雨一倍时间后剩余约 37% |
| `puddle_strength` | 0.7 / 0～1 | 足够湿润时积水的反光强度 |
| `environment_audio` | true | 雨声、屋顶雨声、风声、雷声总开关；编辑器始终静音 |
| `thunder_enabled` | true | 雷声独立开关 |
| `lightning_enabled` | 沿用 true | 雷电视觉和自然事件调度开关 |
| `lightning_center` | [0,0,0] / 每轴 ±100000 米 | 自然落雷区域中心，Y 是指定落点高度 |
| `lightning_radius` | 800 / 50～2000 米 | 落点距中心在半径 0.2～1 倍之间抽样 |

```json
{"jsonrpc":"2.0","id":17,"method":"tools/call","params":{"name":"set_environment","arguments":{"celestial_cycle":true,"time_hours":18,"time_speed":60,"surface_wetness":true,"initial_wetness":0.8,"puddle_strength":0.7,"thunder_enabled":true,"lightning_center":[0,0,0],"lightning_radius":600}}}
```

## 连续昼夜

在环境面板勾选「连续昼夜」，设置世界小时和时间倍率即可启用；默认关闭，避免覆盖旧地图已经手工调整的主光。

客户端从 `time_of_day_hours`、`server_time`、`time_speed` 推算当前时刻，不按登录时间重启。美术周期使用连续方向轨迹和 smoothstep 光色插值；阳光消退后月光逐渐接替，星空和流星可见度连续变化。服务器原三档 preset 仍用于路灯等离散玩法，天空光照不在 preset 边界跳变。编辑器使用隔离预览权威实例，预览推进不改地图保存值。

周期开启时主光方向、颜色、能量和天空/环境光由周期控制；手工数值仍保存在地图中，关闭周期后生效。`sun_shadows` 同时控制日月阴影。这是游戏美术轨迹，不含真实纬度、季节、月相或天文星历。

## 湿润与积水

本地湿润度按当前降雨强度趋近目标，停雨后指数干燥；切地图重置为地图初值，切天气保留累积。个人关闭天气特效只隐藏效果，本地累积仍可继续；从不上传或接受运行时湿润数值。

湿润使用实例 `material_overlay`，不修改基础 PBR 材质、碰撞和导出资源。湿面变暗、粗糙度降低；平缓表面在较高湿度下出现不规则积水反光和雨滴微波纹。程序斑块结合邻近采样高度对低洼区域增强，属于外观近似，不做水量守恒、深度或流体模拟。

相机附近 48×48 米的世界对齐遮雨高度网格，每格 1.5 米；每物理帧最多 32 条向下射线，完成后周期刷新。屋顶可湿，屋顶下地板保持干燥；视觉切除屋顶仍使用碰撞。移动时搬移重叠高度缓存，避免整片湿面闪回干燥。缺少碰撞的数据按干燥处理；窄屋檐和边缘受网格精度限制。编辑器隐藏/排除并移除碰撞的对象不参与遮雨。

当前支持单表面、不透明 StandardMaterial3D 静态地图网格，每个世界最多 512 个附近接收者。多表面、自定义 shader、透明物件、角色/骨骼、受风网格及已有 overlay 的对象跳过，避免覆盖现有渲染；复杂特殊材质仍需单独适配。未新增逐物件湿润配置。保存和刷材质操作基础材质，关闭或卸载效果恢复原显示。

## 室内外声音

中心及四周屋顶探测、四方向近墙探测每 0.2 秒更新。室内程度和屋顶声音混合以约 0.33 秒时间常数渐变。露天以雨声、风声为主；屋顶下增加打击声，室内降低风声与外部雨声。窗口外雨雪仍在世界空间中按碰撞绘制。

声音走 Ambient 总线，尊重音量和天气特效设置。屋顶声、风声和远近雷声使用缓存程序 PCM，没有增加外部音频依赖。当前不区分木瓦/铁皮屋顶，也不是声学传播或混响模拟。

## 空间雷电

可信服务脚本调用 `MockServer.issue_world3d_lightning(map_id,event)`，不列入玩家 RPC。自然雷暴产生相同结构：

```json
{"id":"strike-1","start_at":100,"position":[120,0,-80],"seed":918,"energy":1.2,"height":90}
```

- `id` 非空、地图内唯一；`start_at` 非负服务器单调秒。
- `position` 是世界米制落点，每轴 ±100000；`seed` 为 0～2147483647 整数，决定共享折线和分叉形状。
- `energy` 0.1～4；`height` 30～300 米。事件间隔至少 0.4 秒，最多 64 条；非法/重复事件原子拒绝。
- 闪光包络：年龄 0～0.06 秒为 1，0.11～0.19 秒为 0.25，其余 0，再乘 energy。世界空间发光分叉闪电与有范围、阴影的点光同步显示。
- 到达时间为 `start_at + distance(listener,position)/343`；不同位置听到不同延迟是预期效果，6000 米外静音。近雷冲击更强、远雷更低沉，室内额外衰减，播放中穿门也更新衰减。
- 服务器保留过去 25 秒事件，闪光结束后雷声继续传播。退出雷暴清理未来事件，已发生的雷声仍可到达。客户端按 epoch/id 去重，晚加入不重播已经到达的声音。

落点 Y 不由 MockServer 查询碰撞，地图作者指定区域中心高度；复杂地形由真实服务脚本提供可信落点。当前是视听事件，不包含伤害、火灾或破坏。雷声到点后超过 0.25 秒才首次观察到的旧事件不补播。
