# 3D 物件摆放与排列

2026-10-01。界面和 MCP 复用 `scripts/world_editor/placement_tools.gd`；完整组合保持成员之间的相对位置和朝向。支持方块、旋转物件和带偏移原点/非等比缩放的导入模型。

## 使用方法

- **End：向下贴地**，保持原朝向。**Shift+End：贴地并贴合坡面**。分别移动所选独立物件和完整组合，不互相叠放到彼此身上。
- **V：点选目标表面**，点击实际地面、坡面、墙面或模型表面，整份选择作为一个整体放置，局部 Y 轴贴合法线；**Shift+V** 保持原朝向。画布边框和命中十字提示当前状态，绿色线表示表面法线。**Esc** 取消；未命中时保持选择和地图不变，可继续点选。
- 工具栏 **摆放…** 或 **编辑 → 摆放与排列…** 打开面板，可设置离面距离、向下搜索距离和是否改变朝向。
- 面板内可选择 **X/Y/Z 世界轴**，按负方向边缘、中心或正方向边缘对齐到**最后选中的物件/组合**。参考物件保持原位，其他物件按各自旋转后的包围盒对齐。
- 分布提供**边缘间隙相等**和**中心距离相等**两种方式。按所选轴排序，固定两端，移动中间物件；至少三个独立物件/组合。等间隙模式空间不足时拒绝操作，不强行制造负间隙。

每次贴地、放置、对齐或分布对应一步撤销/重做；没有实际变化不增加历史。已有组合需要完整选中，锁定/隐藏成员先在列表中解锁/显示；避免悄悄拆开组合。单个子项需要独立操作时可先解组。

## 表面计算边界

向下贴地从每个物件/组合的世界包围盒底部中心向下寻找真实表面，默认 100 米。排除本次全部选择以及 NPC/事件标记和隐藏物件；锁定的地面/墙面仍可作为支撑。没有真实支撑面时不会回退到虚拟 Y=0 平面。任一单位没有支撑时整笔失败，不会只移动前几个。

命中的三角面提供位置和法线，摆放距离按所选物件的变换后包围盒计算。导入模型使用导入时保存的本地包围盒和当前三轴缩放；保持模型原资源与尺寸。非平整/凹形模型、大跨度组合和悬空边缘可能留下空隙，当前不是完整的网格接触/防穿透求解器，也没有顶点吸附或持续拖动吸附。

贴合朝向时，最后选中成员的局部 Y 轴作为参考，所有成员共同旋转；不会逐件改变组内朝向。点选表面以组合中心对准落点，沿法线推出到接触平面；向下贴地保持整体 XZ 中心，沿 Y 调整高度。离面距离沿法线计量，范围 0–100 米；向下搜索距离范围 0.01–10000 米。

实际移动的自动瓦片冻结当前造型，脱离邻接；撤销恢复自动关系。固定参考物件、分布两端或无变化的物件不会无故脱离规则。地图保存仍使用原文档 glTF 流程。

## MCP

摆放能力提供以下四个工具；完整当前清单见 [MCP 说明](world_editor_mcp.md)，旧二维工具保持停用：

| 工具 | 参数 |
| --- | --- |
| `drop_selection` | `align_normal=false`、`max_distance=100`、`offset=0` |
| `snap_selection_to_surface` | 必填 `screen: [x,y]`（3D 画布像素）；`align_normal=true`、`offset=0` |
| `align_selection` | 必填 `axis: x/y/z`；`anchor: min/center/max`，默认 `center` |
| `distribute_selection` | 必填 `axis: x/y/z`；`spacing: gaps/centers`，默认 `gaps` |

均操作当前选择，最多 256 个成员，返回 `ok` 与实际修改的 `changed_ids`。界面正在点选表面时，MCP 写操作返回忙碌；`editor_state.surface_placement_active` 可查询状态。坐标范围、只读文档、锁定/隐藏、完整组校验和失败无副作用规则与界面一致。
