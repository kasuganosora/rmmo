  `controls.covered_source_coalescing`，batch stats 保存 `covered_source_waits`。

## 可控慢到达：初版减少工作，但阻碍独立任务重叠

诊断参数 `--prefab-header-delay-ms=500` 只在纹理目录后台 reader 注入延迟，
不暂停主线程，不清 OS 缓存，不修改源文件。每个唯一 header 的第一次任务

## 最终机制与独立验收

`GroundBatcher._prepare_step` 继续完成描述收集和分桶，仅在已经绘制的不透明
cover、immutable runtime append、Deferred 尚未 idle 三个条件同时成立时，
暂缓 ground 的新增和成员替换；building / other 继续按原生产调度执行。
保留原始分桶和描述表，以显式 `await_sources` 状态纳入 pending / full-ready。
完成 worker 不占等待门，仍能被回收与提交；不增加线程数、字节预算或固定延时。

- 新增源继续复用原始描述与分桶；生产者 idle / cover 撤销时自动完成最终 ground。
- `await_sources` 保存当前 roots / excluded；已有源退出导致原始分桶失效时，
  仍能从该请求重新收集，不引用已释放的节点。
- 同步 `sync` / `flush` 绕过等待，clear / retire 清除原有准备所有权。
- 原路径 A/B 开关保持，生产默认启用。保留的是可复现的工作量收益；未增加
  正常暖路径的等待，未证明首次加载的秒级收益，后续若有真实退化证据再调整。

最终 `selective08_A/B.log` 是 GPU 独立压测：8 波、每波 12 个 ground box，
16 成员上限下最终 6 组。A **62 项**、B **76 项**全部通过；最终每组 GPU
surface arrays 逐字节、成员身份与变换均与一次性参考一致，共 2304 顶点。
