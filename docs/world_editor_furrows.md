# 农田垄沟和地形接缝（2026-10-03）

地形面板选择已有地表区域后，设置垄距、高度、方向、田边留白和渐平距离，点击“应用区域垄沟”。选择区域时读回保存参数；移除垄沟保留土壤覆盖。更换区域范围或删除整个区域前须先移除垄沟，避免连带覆盖几何。

当前 3D MCP 的 `set_terrain_furrows` 使用同一 `terrain_furrow_tools.gd` 操作：

```json
{"name":"set_terrain_furrows","arguments":{"id":"farm","terrain_ids":["terrain_a","terrain_b"],"spacing":2.2,"height":0.18,"angle":12,"margin":3,"setback":7}}
```

`enabled:false` 删除配方，其余参数可省略。垄距 0.8～4 米、高度 0.03～0.35 米、方向 −360～360 度（0 度为南北行、90 度为东西行）、渐平距离 0.5～8 米、田边留白 0～12 米。留白默认 0，向区域内部收缩，不改变土壤材质范围。支持同一次请求中的平移与 Y 旋转地块，按世界坐标统一行列相位；保存为局部参数，因此移动整块地形时农田跟随移动。

原高度场作为沟底。生成面分别裁切到区域和每个原地形三角形，在其平面上抬高；不会穿进斜坡或跨越洞格。每块新增一个 cultivation 网格表面，复用区域 PBR 着色器及原地形碰撞体，没有为每条垄建立物件。碰撞、选择边界与建筑放置包围体包含垄高。雕刻会重建并检查垄沟；超过 20 度的实际种植区域拒绝生成。单块最多 48000 三角面、60000 次布尔裁切，单次工具请求最多 120000 三角面；超出时在提交前拒绝。CPU 派生几何有 32 项缓存，换底材不会重新计算垄沟；只改垄沟时复用原 PBR 材质和覆盖纹理，不重新栅格化颜色遮罩。加载线程独立验证 CPU 几何，不读写主线程缓存。

锁定、隐藏、楼层隔离、无效参数、手刷三角面覆盖、倾斜地块、侵入道路或物件、移除物件承托均整笔失败，不增加撤销项。碰撞检测先排除包围体不相交的物件，再检查实际垄沟三角形，避免把两个田块之间的空白也判为实体。多地块修改只产生一个撤销项。`list_terrains.ground_regions.regions[].furrows` 返回配方；原生 glTF 记录、资源依赖及流式运行时复用同一生成逻辑。尚未实现作物、农耕交互或基于摄像机距离的垄沟 LOD。

## 共享接缝

`terrain_neighbors.gd` 在文档层建立派生邻接缓存，统一重合边缘顶点的世界法线，给高度纹理增加邻块采样边框。地形 Shader 的坡度/岸线过渡可以读取块外高度，合批后的纹理数组保留同样的边框。编辑时只刷新发生变化的块及邻块，几何未变化时不重新计算缓存。不修改作者高度、道路、河面或碰撞几何；真实高度裂口不会被这一照明修正掩盖。

当前处理水平或同 Y 旋转、相同网格间距、边缘顶点重合的地块。不同细分密度、X/Z 倾斜或边缘高度不相等的块不自动缝合。边框查询覆盖最长 8 米的当前材质过渡；最细 0.25 米地形使用 33 格边框。

## 验收

- `tools/test_terrain_neighbors.gd`：参考城镇共享法线误差、邻块高度读取、作者数据不变、未修改缓存不重建。
- `tools/test_world3d_furrows.gd`：后台 GPU、真实 HTTP 工具发现和合法/非法调用、保护失败无副作用、跨块行列、UI 参数回显、撤销重做、保存重开、垄脊/沟底射线、角色胶囊横跨垄沟与块边、流式加载。
- `tools/apply_medieval_town_furrows.gd`：临时城镇候选，导入的 Mossy Grass 原色和 12 块参考农田；沿现有道路裁切田界，测量相同镜头下绘制开销。验证后 `--publish` 使用原生原子保存和冲突检测，不复制整份用户地图。
- `tools/verify_medieval_town_terrain_runtime.gd -- --furrows`：候选城镇道路、河道、桥梁的完整运行时回归。

素材清单 `tools/fab_mossy_grass_vcjmej0s.json` 指向用户选定的 [Mossy Grass](https://www.fab.com/listings/dffa11a3-d345-4b88-88bd-8bfd7575500f)。默认包 ID 为 `pack:default:terrain/mossy_grass_vcjmej0s/material`，分类“地表／草地”；5 张运行贴图均为 2048×2048，按归档元数据的 4×4 米扫描范围铺设，颜色为白色乘色、饱和度 1。OpenGL 法线方向通过 Bump 梯度相关性检查；原 ZIP、SHA-256 和来源保存在对应 sources/fab 分类下。原文件的深苔绿保留，亮暗由地图光照决定。

本轮参考城镇验收：12 个农田区域，新增 176999 三角面；同一全景下绘制调用 763 → 795。新进程加载候选的几何缓冲约 74.56 MiB、纹理约 494.73 MiB，包含全景渲染资源，并非单张草地贴图用量。切换镜头和合批状态后等待 30 帧再比较，近景合批/未合批平均 RGB 通道误差约 0.00000795；不等待时会读到尚未稳定的画面。四项后台 GPU 回归、共享法线/高度边框逻辑检查及整城双向过桥/曲线路面步行通过。原始结果保存在 `review_artifacts/terrain_furrows/`。

该轮约 5 分钟的保存瓶颈已在后续单独优化：静态 glTF 数据顺序写出及有界 CPU 几何缓存，首次完整保存约 55 秒、局部改动连续保存约 25 秒。真实几何/贴图、原子发布与恢复验证见 [保存性能](world_editor_save_performance.md)；保存仍同步，后台进度/取消保留待办。运行帧率和保存耗时分别报告。
