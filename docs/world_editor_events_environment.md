# 三维地图事件、环境与遮挡轮廓

第三批基础功能包括五类事件模板、地图光照与雾、运行时玩家遮挡轮廓。UI 与当前 3D MCP 共用 `gameplay_tools.gd`，使用相同的校验、文档记录、撤销与保存流程。旧二维 MCP 继续停用。

2026-10-03 UI 整理：左侧顶部的“工作面板”选择器直接访问全部面板。 文件、编辑操作收进对应顶栏菜单；导入模型/素材管理在“资源”，临时试玩（F5）和出生点设置在“试玩”。场景工具使用整宽工具栏，吸附设置留在画布上方。环境按主题分组，应用按钮固定在滚动区外；事件内容、触发条件、交互范围分别收纳，未选物件时禁用应用/移除。分组展开状态在表单刷新时保留，数字输入未失焦也会提交。后台界面回归见 `tools/test_editor_usability.gd`。

## 事件模板

左侧 **事件** 页中，选择一个物件，选模板、填写参数，点击“应用到所选物件”。也可展开“在指定位置新建事件”，填写脚点坐标后创建独立标记。支持普通物件和导入模型；椅子、旧传送点、敌对或伙伴 NPC 有独立交互，不能直接附加模板。

| 模板 | 参数和行为 |
| --- | --- |
| 对话 `dialogue` | `text` 对话，`once` 是否只执行一次，`empty_text` 再次交互提示 |
| 宝箱 `chest` | `item_id`、`quantity`、`gold`；至少一种奖励；默认只领取一次 |
| 采集 `gather` | `item_id`、`quantity`；默认只采集一次 |
| 传送 `transfer` | 内容根内已有 `.gltf` 的 `map_path`，目标脚点 `spawn`；默认接触触发 |
| 商店 `shop` | 从现有商店目录选择 `shop_id`，沿用服务端价格、购买、出售、回购流程 |

公共参数：`name`、`enabled`、`trigger`（`action` 按 E 或 `player_touch` 接触）、`required_switch`、`required_item`、`required_quantity`、`set_switch`。前置物品仅检查持有数量，不消耗。填写的前置条件同时成立才执行，完成后可以打开一个全局开关。

空间参数都是米：`offset` 从物件原点偏移；`touch_size` 是接触盒的三轴尺寸；`radius` 为按键交互距离。偏移和盒朝向跟随物件旋转，尺寸不随模型缩放改变。新建位置与传送出生位置是脚点；普通标记的物件原点在盒体中心。

模板保存在 `record.event_template = {version: 1, template, parameters}`，完整参数经校验后编译为已有事件页和命令。模板优先于物件原来的事件数据；移除模板保留原数据和物件。生成预览仅展示命令，不执行奖励或传送。

- 锁定、隐藏物件不能修改或清除模板。隐藏依然只影响编辑器，运行时保留事件；要停用运行时事件请关闭 `enabled`。
- 物件复制、分组变换、预制件保存/放置会保留事件。每个副本有独立物件 ID，因此一次性奖励状态彼此独立；全局开关名称仍共享。
- 一次性状态使用已有运行时的地图 ID + 物件 ID + 自开关 A，跨地图往返保持，切换角色/新游戏会话按既有逻辑重置。本批未增加跨登录的存档服务。
- 领取奖励前用当前背包规则检查完整容量；满包或只能容纳一部分时，不发放部分奖励、不消耗一次性状态。
- 按 E 可以找到普通物件和多网格模型上的事件；模型自己的碰撞不会挡住自身交互，其他实体墙会阻挡。接触检测包含两帧脚点之间的线段，减少快速跨过小区域时漏触发。
- 传送目标沿用外部内容根约束，拒绝越界、链接目录和不存在的文件。目标地图是引用，保存预制件不会递归打包另一张地图；移动地图文件后应更新引用。

## 环境与轮廓

左侧 **环境** 页提供白天、黄昏、夜晚预设，以及主光方向/颜色/强度、太阳光投影、环境遮蔽、环境光、背景色、雾开关/密度/颜色。点击“应用环境设置”即时预览；设置保存到 `map_meta.environment`，重开编辑器、进游戏、地图传送均会应用。改变预设会填入该时段的光照值，仍可继续修改。游戏中的 N 键临时切换昼夜，不写回地图文件。

`sun_shadows` 控制太阳光投影，避免屋檐、窗框和梁柱缺少空间层次；`ambient_occlusion` 控制接缝、墙角和接触处的屏幕空间环境遮蔽。两项默认启用，可由 UI 或 MCP 关闭，保存、撤销/重做语义一致。太阳阴影最大距离 120 米；环境遮蔽使用 Godot Forward+ SSAO（半径 1.2 米、强度 1.4），其他渲染后端不保证该效果。旧地图缺少两字段时使用新默认值。

玩家遮挡轮廓可设置启用、颜色和 1～6 像素宽度。游戏根据相机到玩家头、躯干、脚附近的射线判断是否被实体挡住；遮挡时绘制玩家实际几何的外轮廓。蒙版使用同一套角色网格，因此保留蒙皮、装备及 GPU 变形；换装新增的几何会自动加入。无遮挡或关闭时停止额外的蒙版渲染。3D **可见层 20** 为本地玩家蒙版保留，不能给场景物件使用。

编辑器没有可操控玩家，轮廓效果需在游戏中查看；雾与光照可以在编辑画布预览。无碰撞装饰不会触发遮挡检测；当前不是逐像素深度判定，极窄遮挡物可能落在三条检测射线之间。

## MCP

当前总计 69 个工具；协议与安全约束见 [world_editor_mcp.md](world_editor_mcp.md)。事件/环境工具：

| 工具 | 用法 |
| --- | --- |
| `list_event_templates` | 五类模板默认值及参数 schema |
| `list_event_resources` | `query`、`offset`、`limit` 分页返回物品/商店 ID；分别分页并返回各自总数 |
| `create_event_template` | `template`、`position` 脚点、可选 `parameters` |
| `set_event_template` | `id`、`parameters`、可选 `template`；同类型增量更新，切换类型重新用默认值 |
| `clear_event_template` | `id`；一次撤销，只清模板 |
| `get_environment` | 返回完整有效环境，包括旧地图默认值 |
| `set_environment` | 直接传需要修改的环境字段；`preset` 先填预设，同次显式字段再覆盖 |

```json
{"name":"create_event_template","arguments":{"template":"chest","position":[3,0,2],"parameters":{"name":"庭院宝箱","gold":25}}}
{"name":"set_event_template","arguments":{"id":"obj_2","template":"dialogue","parameters":{"text":"欢迎来到庭院。","set_switch":"met_gardener"}}}
{"name":"set_environment","arguments":{"preset":"sunset","fog_enabled":true,"fog_density":0.015,"outline_enabled":true,"outline_width":3}}
{"name":"set_environment","arguments":{"sun_shadows":true,"ambient_occlusion":true}}
```

调用时使用真实物件/目录 ID。非法字段、数量、物品或商店、路径、保护状态均在修改前拒绝；无变化操作不增加撤销。文档、预制件、恢复草稿和运行时加载均校验模板/环境结构，损坏的已编写地图不会静默退化为无事件场景。

## 第三人称室内楼层隐藏（2026-10-02）

环境页新增 `interior_cutaway`（默认 false；2026-10-04 按用户要求关闭）和 `indoor_camera_distance`（默认 3.2 米，范围 2～5 米）。配置走同一 UI/MCP 事务，可撤销重做并保存；角色相机效果在试玩/游戏中查看。

只有第三人称角色处于所属生成建筑内部，且从相机期望位置射向角色注视点的**第一次碰撞**是其上方楼板或天花板时才激活：

- 相机 → 天花板/上层楼板 → 人：触发。
- 相机 → 人：不触发。
- 相机 → 普通物体/墙 → 人：不触发；普通物体后面还有楼板也不触发。

触发后隐藏天花板和当前层以上构件，保留当前层地面、墙体、楼梯；隐藏仅影响本地显示。角色碰撞、导航和保存文档不变，点击拾取、相机避障与人物轮廓跳过隐藏层。遮挡判定仍查询全部物理楼板，避免隐藏后立即误判无遮挡而闪烁。持续无遮挡 0.2 秒后恢复；离开室内、禁用配置或切换第一人称/VR 立即恢复。

第一人称/VR 不运行该隐藏规则，也不处理第三人称的相机跟随与鼠标旋转。程序控制器须调用 `world.set_camera_mode("first_person")` 或 `world.set_camera_mode("vr")` 后接管相机，回到第三人称用 `"third_person"`。这是模式隔离接口，不代表已经实现第一人称或 VR 控制器。

室内第三人称限制跟随距离、平滑阶梯引起的注视点高度变化，并用半径 0.2 米球体检测可见障碍。检测楼板遮挡使用避障缩臂前的位置，否则相机先缩到楼板下面会让隐藏永远无法触发。

范围为保留建筑实例登记的生成房屋，支持旋转主体、单层附属房及城中村屋顶楼梯间。开放院落、阳台和露台不算室内；解除关联的普通构件、快照预制件和任意导入模型尚无室内体积登记，不能自动套用此功能。

```json
{"name":"set_environment","arguments":{"interior_cutaway":true,"indoor_camera_distance":3.2}}
```

`test_world3d_interior_camera.gd` 验证三类射线、普通物件位于楼板前、墙体、切层、楼顶室内/室外、第一人称/VR 恢复、关闭设置、流式卸载重载、保留物理碰撞与文档无变化，并在后台 GPU 输出同一视角隐藏前后的截图。

## 3D 天气更新（2026-10-02）

夜空新增星空亮度、流星开关 / 频率；时间新增小时和倍率，倍率0暂停。游戏 / F5 的时间由服务器推进，跨6、17、20点切换白天 / 黄昏 / 夜晚；属性面板编辑初始时间。运行时天气、时钟、风、星空种子、普通流星 / 火流星 / 流星雨和闪电统一由服务器下发，详见 [3D 环境同步](world3d_environment_sync.md)。

属性检查器新增「柔性物件受风」：按网格配置植被 / 布料、摆幅、刚度、局部固定边和遮挡检测，环境中的风速 / 风向同时驱动它们及雨雪、云。MCP 对应 `get_object.wind_meshes` 与 `set_object_properties.wind`，支持撤销、保存重开和流式加载。默认不自动吹弯所有模型；旗杆等刚性节点应排除。天空新增黄昏冷暖渐变、迎光云色及夜间月盘 / 星点，详情及材质限制见下方天气文档。

环境面板与当前 3D `get_environment` / `set_environment` 已共用晴、雨、雷暴、雪、雾配置，新增天气强度、风速/风向、过渡时间、天空与闪电开关。雨雪为世界空间粒子，并有物理遮雨和碰撞水纹；支持撤销、保存和试玩。字段、精确边界和后台 HTTP/GPU 验收见 [3D 天气与美术](world3d_weather.md)。

## 环境效果扩展（2026-10-02）

连续昼夜、本地地表湿润/积水、室内外声音和空间雷电均复用当前 3D 环境操作，详见 [配置与验收](world3d_environment_effects.md)。运行时湿润度不保存到服务器、不强制同步；雷电事件继续由服务器给出位置、种子和时间。
