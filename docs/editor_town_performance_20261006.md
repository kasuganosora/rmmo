# medieval_river_town 编辑器性能修复（2026-10-06）

用户将编辑器严重卡顿、游戏从出生点走到桥附近卡顿列为最高优先级，随后补充只移动位置仍耗时导出材质与贴图，同为最高优先级。已授权持续实施；游戏独立路线记录见 [河桥性能复核](game_bridge_performance_20261007.md)，不能用编辑器结果代替。

## 已实施

- 整栋建筑刚体移动更新原节点、拾取碰撞体和建筑元数据，保留独立构件、楼层、屋顶及活动件语义，不再因移动重建全图。复制和改变结构仍使用原有完整重建。
- 选择变化立即释放选中物件的渲染批次，未变物件保留几何描述缓存，重组走原有分帧准备流程。尺寸和材质变化单独使源描述失效。
- 纯位置/旋转撤销、重做经全量差异预检后局部恢复，包含当前未选中、已重新合批的物件。几何、记录顺序、地图设置、楼层隔离等不满足条件的变更回退原流程。
- 拖动事务缓存本次选择的活记录，避免每次鼠标事件反复扫描全部记录；结束即丢弃，不能跨撤销或切图复用。建筑拖动不再提前复制不会使用的全图快照。属性面板只刷新变换数值。
- 带表面材质的刚体变换复用局部网格；尺寸变化仍重建，特殊世界坐标几何保留原处理。
- 建筑碰撞预检跳过边界确定不相交的地形块，相邻地形仍执行原有精确判定，不改变手动布置规则。
- 城镇概览缓存静态绘制与物件边界；相机标记单独刷新。道路缓存世界坐标边线，透视视图保守剔除屏幕外道路，正交平移复用已提交的绘制指令。预览、路网变更、撤销及切图使相关缓存失效。
- 新编辑器会话风场预览默认关闭；环境面板可打开。UI 和 MCP `set_editor_wind_preview` 共用操作，`editor_state.wind_preview` 可查询。关闭会恢复原材质并停止风场扫描、遮挡及逐帧更新；不修改地图、游戏默认值或撤销历史。
- 打开地图增加阶段、计数及耗时显示；文件读取/JSON 解析后台进行，场景构建分帧，失败保留旧文档。MCP 同步增加后台作业与进度查询。
- 缺失素材缩略图按可见范围、输入空闲逐件补生成并写磁盘缓存；UI/MCP 可重试失败条目。已有 PNG 的浏览仍不加载模型。
- 按住中键时 WASD 水平移动镜头，↑/↓ 垂直升降，Shift 加速；失焦或释放停止，MCP 共用位移操作。
- Grok 复核确认的隔离视图取消/整栋拖动结束重复重建已消除；结束拖动也复用事务活记录。草稿数量提示不再计算源地图全文哈希。
