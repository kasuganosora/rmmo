# 3D 地图草稿与关闭保护

2026-10-01。界面和 MCP 共用 `document_safety.gd` 的保存、恢复和关闭操作；独立草稿由 `draft_store.gd` 管理。

## 使用方法

- 默认每 **60 秒**保存已完成修改的恢复草稿。文件菜单的 **自动草稿设置…** 可关闭或设置为 15–600 秒；设置只影响当前编辑会话。
- **文件 → 保存草稿** 可立即保存。草稿不会覆盖正式 glTF，也不会清除“未保存”状态。拖动、画笔、框选、点选表面或文字输入期间暂缓自动保存。
- **文件 → 恢复草稿…** 或顶栏 **恢复草稿 (N)** 打开列表；按时间倒序显示地图、时间（UTC）、物件数量和磁盘版本是否变化，每页 50 项。选择后可查看完整地图路径、恢复或删除草稿。
- 恢复先校验完整快照，再备份当前未保存内容，最后替换编辑器内存。正式地图保持不变。同一地图的恢复可一步撤销/重做，包括物件、地图元数据和保存冲突基线；跨地图恢复重建历史，原未保存内容保留在独立草稿中。
- 点击窗口关闭按钮或返回登录时，先提交未完成的数值输入和编辑事务，再检查修改。有修改时提供 **保存并关闭**、**保留草稿并关闭**、**放弃修改并关闭**、**继续编辑**。保存或草稿写入失败会保持编辑器打开；返回登录使用相同处理。

如果草稿对应的正式地图已被其他窗口修改，恢复不会解除保存冲突保护；需检查内容并另存为其他路径。另存为失败不会改变当前地图路径。

## 存储和恢复边界

草稿保存在外部内容根的 `cache/world3d/editor_recovery/`，每个地图、每个编辑会话使用独立 ID。同一会话只更新自己的最新草稿，原子替换保留 `.previous`；成功正式保存或明确放弃修改只清理本会话对应草稿，其他窗口及历史会话的草稿保留，由恢复面板管理。

草稿包含物件记录、地图元数据、下一个物件 ID、原地图路径和磁盘签名。小型头信息供分页列表读取；恢复时校验正文 SHA-256、格式、标识、变换及模型路径。单份最大 32 MiB、最多 100000 件物件。地图及模型引用必须位于配置的外部内容根，拒绝链接和越界路径；MCP 使用草稿 ID，不能指定任意草稿文件。

草稿不打包模型、贴图等外部依赖。模型丢失时恢复会返回缺失清单并显示占位物，正式保存仍需先修复资源。异常退出可恢复**最后一次成功保存的草稿**；最近一次草稿之后的输入不在恢复保证内。写入中断留下的暂存文件不参与恢复列表，已有完整草稿保持可读。`.previous` 是原子替换备份，当前面板不提供它的版本选择。

正式 glTF 保存继续使用原有原子写入、上一版备份和多窗口冲突检查。草稿序列化和文件发布目前在主线程同步执行；大型地图可能短暂停顿。

## MCP

草稿与关闭保护提供如下六项工具；当前完整清单见 [MCP 说明](world_editor_mcp.md)。旧二维 MCP 仍停用且源码保留。

| 工具 | 参数与结果 |
| --- | --- |
| `configure_autosave` | 可选 `enabled`、`interval_seconds`（15–600）；返回会话设置 |
| `list_editor_drafts` | `offset=0`、`limit=50`（最多 100）；返回分页草稿、总数、来源及 `source_changed`，正文在恢复时校验 |
| `save_editor_draft` | 无参数；返回 `draft_id`、`saved_at`，未变化时可带 `unchanged=true` |
| `restore_editor_draft` | 必填 `draft_id`；当前有修改时须 `discard_changes=true`，先备份当前内容；返回 `map_path`、`source_changed`、`undoable`、`missing_assets` |
| `discard_editor_draft` | 必填 `draft_id`；删除该草稿及其上一版，当前地图不变 |
| `close_editor` | 必填 `action: save/keep_draft/discard/cancel`；前三项关闭当前编辑器进程，`cancel` 取消待关闭提示，仅在用户明确要求关闭时调用 |

`editor_state.autosave` 返回开关、间隔、最近成功保存时间、最近错误和 `close_pending`。关闭确认期间其余写操作拒绝执行，只读查询仍可用。读取正式地图失败后仍可查询/恢复草稿、配置自动保存、删除指定草稿或关闭；失败产生的空文档不能覆盖恢复草稿或正式地图。

## 验证

`tools/test_world3d_recovery.gd` 使用临时地图、真实 HTTP 和独立子进程，覆盖六项工具、非法参数、草稿损坏无副作用、定时保存与忙碌跳过、同图撤销/重做、外部写入冲突、另存为、不同会话草稿隔离、失败保存留在编辑器、强杀写入进程后读取上一份完整草稿，以及三种真正关闭进程的结果。

GPU 模式额外检查未提交数值输入的关闭保护、恢复面板与跨图备份、设置按钮和 1024 像素布局。通过 `tools/run_godot_background.py` 在不激活的独立桌面运行，截图和日志保存在外部 `review_artifacts/editor_recovery/`。同时回归原 MCP、变换、组合和原子保存测试。
