## 导出与运行时

- `tools/export_town_props_runtime.py` 读取原始 Blender 样品，在独立输出中应用修改器、去除摄影棚/相机/灯具，并重置各模型地面原点。保留原 `.blend`，不覆盖艺术母版。
- 程序化实体材质烘焙为 2048px 基色、切线法线、粗糙度贴图；基色烘焙不包含灯光和阴影。扫描叶片保留原透明纹理与 UV。GLB 包含纹理，库导入后使用不可变内容文件。
- `tools/finalize_town_prop_materials.py` 将原扫描叶片的独立 Opacity 通道合入 RGBA，显式使用 alpha mask（不改原 RGB），修复游戏里出现方形叶卡的问题。玻璃透射扩展转换为引擎可用的透明混合近似；灯罩与药瓶保留独立玻璃材质。旗布法线强度降低以抑制远处摩尔纹。叶片、布旗、火焰不生成实体碰撞，刚性结构保留碰撞。
- 静态部件按功能合并；彩柱木身与金丝带分开，棚布与包边分开，货物与棚架分开；彩旗逐面保留独立网格及原图案 UV。柱色修改时应只选 `PostBody`，丝带保持金黄。当前沿用编辑器材质与变换功能；Blender 参数配方不自动变成新的游戏参数面板。
- 布旗携带明确 `rmmo_wind` 元数据，使用现有游戏风场、顶部固定与 GPU 变形；刚性柱和丝带不随旗面摆动。支持原有 UI/MCP 的 `set_object_properties.wind`；显式关闭风会移除模型默认风设置，保存重开有效。
- 小壁灯的独立烛火网格标记 `rmmo_small_wall_lantern`，进入共享昼夜灯具调度。白天隐藏烛火并关灯，夜间发暖光；不采用每灯计时器或走近开启。已有蓝色晶石路灯保持原效果。
- 通过原生 `AssetLibrary.import_file` 和 `PrefabLibrary.capture/place` 发布共享资源库，沿用选择、变换、撤销、保存冲突检测与资源依赖。没有新增 MCP 工具；现有资产查询、放置、风场和环境工具覆盖本次接入。
