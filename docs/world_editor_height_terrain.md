# 高差地形、建筑拼接与自定义套件

2026-10-01，第二批地图编辑能力。编辑器与当前 3D MCP 共用 `auto_tile_stroke.gd`、邻接规则、校验和撤销事务；二维 MCP 保持下线。

## 编辑器操作

素材库新增“高台 / 悬崖（自动）”“楼梯（自动）”“屋顶（自动）”“桥 / 栏杆（自动）”。选中后，上方设置格宽和高度；点“高差 / 套件…”或左侧“拼接”页调整参数、选择或导入套件。

| 类型 | 工具栏高度 | 拼接页参数与行为 |
| --- | --- | --- |
| 高台 / 悬崖 | 顶面高度 | 基底高度，顶面需高于基底 0.1～1000 m。同格宽、同基底属于同层；重刷顶面高度保留 ID。邻格等高时去掉内部崖面，邻格较低时只露出实际高差，擦除后邻格自动补边。 |
| 楼梯 | 下端高度 | 升高 0.1～8 m、向北/东/南/西上升。程序模型台阶不高于 0.18 m；相邻桥/道路按楼梯的上、下端高度与方向开口。 |
| 屋顶 | 檐口高度 | 升高 0.1～8 m。同檐口、同升高的屋顶连片，内边升至屋脊，外边落到檐口，凹角按八邻域处理。不同升高分开收边。 |
| 桥 / 栏杆 | 桥面高度 | 栏杆高度 0.3～3 m。四边默认有护栏，连接同高度桥、路、高台或对应楼梯端点后自动开口。桥面厚 0.2 m。 |

默认升高 2 m，栏杆高 1 m。UI 基底默认 -2 m，方便在默认顶面 0 m 开始绘制；MCP 省略 `base_height` 时为 0 m。格宽仍为 1/2/4/8 m，不自动重采样不同格宽。

左键连续铺设，Shift+左键擦除，松手提交一笔，Esc 取消整笔。重刷相同参数不添加撤销记录。锁定/隐藏格不可被画笔替换或擦除。邻接仍按逻辑格计算，隐藏不移除运行时地形。自由变换、复制、保存预制件或刷表面材质时，冻结当前造型并脱离自动邻接；撤销可以恢复。

## MCP

`paint_auto_tiles` 新增 `cliff/stairs/roof/bridge`，保留原有五类；新增参数 `base_height`、`rise`、`direction`（0 北、1 东、2 南、3 西）、`rail_height`、`kit_id`。参数只允许用于对应类型，超界或套件类型不匹配会在开始事务前拒绝。点的 Y 仍由 `height` 替代。

```json
{"name":"paint_auto_tiles","arguments":{"family":"cliff","points":[[0,0,0],[8,0,0]],"height":3,"base_height":0,"cell_size":4}}
{"name":"paint_auto_tiles","arguments":{"family":"stairs","points":[[4,0,4]],"height":0,"rise":3,"direction":0}}
{"name":"paint_auto_tiles","arguments":{"family":"bridge","points":[[12,0,0],[20,0,0]],"height":3,"rail_height":1}}
{"name":"paint_auto_tiles","arguments":{"family":"roof","points":[[0,0,12],[8,0,12]],"height":4,"rise":1.5}}
```

`import_auto_tile_kit(path)` 导入内容根内的 JSON 清单，返回 `kit_id`。`list_auto_tile_kits()` 列出已导入套件的名称、类型、ID 和模型变体数。将 ID 传给 `paint_auto_tiles.kit_id` 即可绘制，省略则使用内置模型。`get_object` 返回完整的 `tile3d`（含邻接、崖面比例和套件快照）。

## 自定义静态 GLB 套件

每套只对应一种类型。清单不超过 64 KiB，名称不超过 120 字符，每个 GLB 不超过 16 MiB、16 个材质面、50,000 个顶点。必须是 GLB 2.0，纹理和缓冲数据内嵌；不支持蒙皮、动画或形变。模型保留原材质、UV 和节点局部变换，合并为静态网格。所有路径遵守内容根和非链接目录限制。

最小高台清单示例（模型文件与清单放在同一目录）：

```json
{
  "version": 1,
  "name": "石砌高台",
  "family": "cliff",
  "pieces": {
    "top": "top.glb",
    "edge": "edge.glb"
  }
}
```

模型坐标是单位格，X/Z 边界为 -0.5～0.5，Y 范围为 -0.5～0.5，原点居中。引擎根据格宽、总高度缩放：

- 高台 `top` 是 Y=0.5 的顶面；`edge` 是朝北（-Z）、位于 Z=-0.5 的整高侧面。系统将侧面旋转到暴露方向，并按真实高差缩短；不要在侧面模型内重复放顶面。
- 楼梯只需 `default`，从南端（Z=0.5，Y=-0.5）向北端（Z=-0.5，Y=0.5）上升，系统按方向旋转。自定义楼梯台阶比例由模型作者控制。
- 道路、墙、桥以四向掩码命名模型：北=1、东=2、南=4、西=8。可只提供 `0/1/3/5/7/15` 六个旋转代表，系统自动旋转匹配；也可提供全部 16 种。桥模型需自行包含对应开放方向的桥面和栏杆。
- 草/土/水/屋顶使用八邻域：东北=16、东南=32、西南=64、西北=128。对角只有两侧方向均连通才有效，共 47 种；可提供 15 个旋转代表 `0/1/3/5/7/15/19/23/27/31/55/63/95/127/255`。清单必须覆盖所有有效状态（含旋转），否则导入拒绝。自定义地形材质过渡由模型提供。
- 屋顶模型的檐口在 Y=-0.5、屋脊在 Y=0.5；连接边应与旋转后的邻块重合。桥的归一化高度包含桥面厚度和栏杆，改变栏杆高度也会整体缩放自定义桥模型；需要固定构件比例时，使用为目标尺寸制作的套件。

导入前校验全部依赖，通过后复制到内容根的 `cache/world3d/auto_tile_kits`，文件按内容摘要命名，不修改来源。套件快照随地图记录保存，源清单后续改变不会暗中改变地图。模型依赖缺失时拒绝正式保存；运行时遇到损坏套件会明确加载失败。

保存预制件会把套件 GLB 一起复制到预制件资源库，以相对路径记录；资源库整体搬迁后仍可放置。地图记录本身沿用工程现有的绝对外部资源路径语义。草稿、保存重开、表面材质覆盖沿用原流程。

## 验收与边界

`tools/test_world3d_height_terrain.gd` 使用独立临时地图和资源包，通过真实 HTTP 验证工具发现、画笔、导入/列表、非法参数无副作用、锁定、撤销重做、保存重开、依赖缺失保护与预制件搬迁；验证道路/楼梯/屋顶/桥套件旋转，真实 UI 笔画与 Esc，运行时崖面高度、桥栏杆开口、角色物理上楼梯。Windows 图形测试使用 `tools/run_godot_background.py` 独立后台桌面。

这是规则地形和模块拼接，不包含任意曲面雕刻、洞穴、自动生成整栋建筑、桥墩、楼梯自动寻路或自动测量两端高差。楼梯的方向与升高需设置；陡峭或过窄的自定义楼梯不保证角色可走。内置模型用于搭建与验证，正式美术可以通过套件替换。

事件模板、环境与遮挡轮廓已进入第三批，见 [world_editor_events_environment.md](world_editor_events_environment.md)。楼层隔离显示、临时副本试玩和指定出生点已交付，见 [world_editor_playtest_floors.md](world_editor_playtest_floors.md)。

整栋建筑的外观和室内生成由独立蓝图工具提供，见 [world_editor_buildings.md](world_editor_buildings.md)，不属于自动瓦片画笔。
