# RMMO 模型交付验收

用户于2026-10-11要求：**每个新模型制作完成后，都按本标准review，不等用户另行提醒。** 这是制作流程的收尾步骤，不是后台自动监控。资产变更后复验受影响项；纯命名/文档变更不重复GPU或整城测试。读取当前项目AGENTS和用户最新要求，阶段要求优先。

## 执行入口

1. 读 [review-standard.md](references/review-standard.md)，执行每模型必查项，并按类型选择附加检查。开始前登记参考、阶段、实际导出文件和SHA；不能只验制作软件里的母版。
2. 建筑、家具、材质复验或用户指出重复问题时，按 [反复问题与处理经验](references/recurring-failures.md) 选择结构、光学或表面层次检查；正式接入和验收图片清理分别读取其中第 4、5 节。具体公会造型是该资产的要求，不套成所有模型的样式。
3. 在RMMO/Godot中读 [rmmo-tools.md](references/rmmo-tools.md)，复用当前生产管线和隔离验收工具。工具缺少某类支持时补适配或如实记录待验，不能用静态模型工具误判骨骼模型，也不能跳过失败便宣布通过。
4. 按 [报告模板](assets/review-report.template.md) 保存每件模型的结论与证据。小模型可用短报告、同批可共用环境和基线，但每件必须有独立SHA、检查状态和适用范围。

## 必须保持的判断原则

- 先确认轮廓、结构、比例、用途和用户修正，再讨论成本。新建模型以设定/参考及可用母版作基线；优化同一外观时以已认可导出资源作A/B基线。用户明确要求的外观改变单独记录，不误判为优化损失。
- 用户指出的问题进入闭环清单：参考要求 → 受影响部件/独立预制件/装配版本 → 原因 → 修复 → 实际导出复验。红框是症状位置，不是修复范围；排查共享材质、生成器和同类部件，保留已正确的不同样式。仅改一处截图或仅改母版不能关闭问题。
- 成本拆开记录：源文件、native文件、唯一/当前可见三角面、材质与draw calls、图片解码字节、含mip的GPU预算、保守准入峰值、实测RSS/VRAM/耗时。没有测到的字段写未测；磁盘压缩率不代表显存收益，实例数不乘共享纹理内存。
- 每个模型都评估减面、LOD和纹理成本，但不强制减面比例、固定2K上限或给简单模型制造LOD。先处理经证实的浪费；保留母版和回退版本。写实画质优先，有可见非预期退化就回退或换方案。
- 清理沿完整依赖可达图进行，保留材质通道、扩展、自定义extras、共享bufferView、skin/animation等引用。只按图片名、图片表或texture.source计数删除不安全。验收目录也可能含模型依赖和唯一画面证据，清理前区分文件用途并查报告引用；不能按目录名或图片扩展名整批删。未知引用停止该项破坏性清理，保留原资源；其余检查继续。
- 同相机、灯光、曝光、尺寸和相同姿态/风时刻对比近、中、远、关键细节；透明模型另看叶缘/发丝和投影。先真实导入保存重开再拍候选。无损宣称须有语义/字节及确定性画面证据；有损候选须人工看图。MAE很低、总alpha覆盖率相近或自动比较pass均不等于画质通过。
- 用户于2026-10-14补充：**发送给 OpenAI 的验收截图实际编码为有损 WebP，quality=90**，保持原尺寸与色彩；不是只换格式，已有 WebP 也不能直接跳过。用 [prepare_review_image.py](scripts/prepare_review_image.py) 生成上传图与压缩记录；仅在 SHA 和参数记录一致时复用已压好的图，避免反复压缩。精确像素比对使用本地无损数据，上传仍用质量90副本；原 PNG 无需默认保留，有本地比对/证据引用时先保留再迁移。替换归档证据同步路径与新 SHA，并确认查看工具实际发送的仍是 WebP。
- 保留碰撞、独立实例与选择、活动件、房屋楼层/屋顶隐藏、风场/动画以及LOD语义。游戏无碰撞不代表编辑器不可选择；渲染合批不是把源模型的编辑语义合并掉。
- 按既有授权继续工作，无需每件模型再次请用户确认。review本身不新增正式地图发布、缓存覆盖、插件安装或购买授权；已获授权的接入继续正常执行。

## 交付状态

分别写明 `资源审计`、`画质`、`运行管线`、`游戏/编辑器接入` 的 **通过 / 不通过 / 待验 / 不适用及原因**。检查结果必须绑定文件SHA和管线版本，改文件后旧通过结果不能直接沿用。

- 白模允许纹理项不适用，但比例、结构、通行、可编辑性与几何成本仍必查；不得把白模验收称为最终材质验收。
- 资源侧通过、正式场景尚未接入时，可交付“独立候选已验收，接入待验”，不能称“游戏完整验收通过”。
- 必要项失败或有可见损失，修复后复验对应范围；环境/接口不可用则保存候选和具体缺口，不捏造通过。
- 源材质参数、脚本通过数和“已截图”均不能替代实际查看。未看过的目标区域、缺失的历史图片、尚未到位的室内反射/照明分别记录，不能用总体通过覆盖这些缺口；库中可用与正式地图已部署分开写。
- 汇报主要变化、成本证据、选中/退回版本和遗留限制，附报告链接。不要把一次采样推广为所有视角、灯光和连续动画都已验证。
